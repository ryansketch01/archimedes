# CISA adds Fortinet FortiManager CVE-2026-29841 to KEV catalog (CVSS 9.3, active exploitation, ransomware-known flag)

## Summary

CISA added CVE-2026-29841 (Fortinet FortiManager / FortiManager Cloud) to the Known Exploited Vulnerabilities catalog on 2026-05-04 with the federal patch deadline 2026-05-25 (BOD 22-01, 21-day window). The flaw is an authenticated remote code execution via crafted FGFM (Fortinet management protocol) packet with privilege escalation to root on the management plane; CVSS 9.3 per Fortinet PSIRT (FG-IR-26-128). CISA's KEV listing carries the "known to be used in ransomware campaigns" flag set to true. Mandiant publicly disclosed late-April 2026 exploitation against a "limited number" of internet-exposed FortiManager appliances; observed activity includes harvesting of managed-FortiGate device configurations from compromised FortiManagers — functionally a network-wide skeleton key for downstream lateral access. No public IOCs in the cluster yet; Mandiant indicated indicators forthcoming. No tracked-roster actor attribution at present (Mandiant's UNC cluster is unnamed).

- **Vendor / product:** Fortinet FortiManager (and FortiManager Cloud)
- **Class:** Authenticated remote code execution via crafted FGFM packet → root on FortiManager
- **CVSS (Fortinet PSIRT):** 9.3 (Critical)
- **Affected versions:** FortiManager 7.6.0–7.6.3, 7.4.0–7.4.6, 7.2.0–7.2.9, all 7.0.x, all 6.4.x (EoES — no fix planned)
- **Patched versions:** FortiManager 7.6.4, 7.4.7, 7.2.10
- **Cloud-hosted:** Fortinet patched FortiManager Cloud instances on 2026-04-29 per the advisory
