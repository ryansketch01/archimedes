## Summary

CISA added two CVEs to the Known Exploited Vulnerabilities catalog on 2026-05-21, both carrying federal-civilian remediation deadline 2026-06-04 under BOD 22-01. ## Technical detail

### CVE-2025-34291 — Langflow Origin Validation Error (CORS+SameSite refresh-token RCE)

- **CWE**: CWE-346 (Origin Validation Error)
- **Mechanism class**: Overly permissive CORS configuration combined with SameSite=None refresh-token cookie. A malicious webpage performs cross-origin credentialed requests against the refresh endpoint; obtained tokens permit access to authenticated endpoints, enabling arbitrary code execution and full system compromise per CISA-KEV shortDescription.
- **Affected product**: Langflow — open-source low-code AI agent / LLM orchestration platform (visual flow builder for LangChain/LangGraph workflows). Deployed by enterprises building internal AI-agent pipelines.
- **Patched version**: 1.9.3 (per Langflow release-tag reference in KEV)
- **CVSS**: Not provided in KEV record; NVD record carries the score.
- **A&D relevance**: Tier-2. Primes and DIB Tier-1 suppliers building internal AI-agent / LLM-orchestration platforms may run Langflow. Federal-civilian deadline 2026-06-04.

### CVE-2026-34926 — Trend Micro Apex One on-premise pre-auth-local directory traversal

- **CWE**: CWE-23 (Relative Path Traversal)
- **Mechanism class**: Pre-authenticated local attacker modifies key table on the Apex One server to inject malicious code that deploys to agents on affected installations per CISA-KEV shortDescription. Pre-auth-local requirement narrows blast radius (attacker needs initial-access foothold) but server-side key-table modification → agent payload deployment makes this a high-impact post-compromise pivot — the EDR control plane becomes a malware-distribution mechanism for all endpoints managed by that Apex One server.
- **Affected product**: Trend Micro Apex One (on-premise) — enterprise EDR/AV product. Widely deployed across DIB Tier-2/3 supplier estates where Trend has historical mid-market and SMB-government penetration.
- **Patched version**: Per Trend Micro KA-0023430 vendor advisory.
- **CVSS**: Not provided in KEV record; NVD record carries the score.
- **A&D relevance**: Tier-1 direct. Trend Micro Apex One is a known enterprise-EDR fixture across DIB Tier-2/3 estates. KEV inclusion implies CISA-observed active exploitation. Federal-civilian deadline 2026-06-04.

### Cross-vendor EDR-control-plane targeting pattern (Archimedes-side framing, B3)

Adversaries appear to be demonstrating systematic targeting of EDR control planes across vendors. **This is cross-vendor pattern observation, not actor attribution.** Sector-shape framing only; no source attributes either CVE to a specific actor.

### KEV cadence anomaly (Archimedes-side framing, B3)
