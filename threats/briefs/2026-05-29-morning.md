# Morning Brief — 2026-05-29

**Per MSRC's vendor statement and two trade-press relays of it, three of six Chaotic Eclipse Windows zero-days are now actively exploited; no independent IR-firm telemetry corroborates this yet.** MSTIC separately discloses an active npm typosquat campaign (`vpmdhaj`) stealing AWS, Vault, and npm publish tokens. **MSTIC discloses `vpmdhaj` npm typosquat campaign — AWS, Vault, GitHub Actions, npm publish-token theft**
- MSTIC published 2026-05-28 23:04 EDT. A single npm maintainer alias (`vpmdhaj`, email `a39155771@gmail.com`) published 14 typosquat packages in a 4-hour window mimicking OpenSearch / ElasticSearch / DevOps libraries. Payload via `preinstall` / `install` / `postinstall` lifecycle hooks harvests AWS IMDSv2 + ECS task-role creds, AWS Secrets Manager (16+ regions), HashiCorp Vault tokens, GitHub Actions secrets, npm publish tokens. Two-stager architecture; Gen-2 abuses the legitimate Bun runtime to defeat naive network detection. npm took the packages down.
- **Lineage UNRESOLVED.** Defender published `Trojan:JS/ShaiWorm` + `ObfusNpmJs` + `SupplyChain` — the `ShaiWorm` family-name is **Defender's internal-classification signal, not analytic attribution to TeamPCP** ([roster #001](threats/threat-actors/_roster.yaml)). MSTIC declines to name an actor; Hard Rule 2 binds Archimedes to that silence. Analyst ACH ties at rank-1: **H2** (distinct actor reusing public Shai-Hulud TTPs) and **H3** (TeamPCP-adjacent affiliate or successor); direct TeamPCP continuation (H1) is **unlikely**. Tripwire: **Wiz / Snyk / StepSecurity / Semgrep / Aikido relay within 72h** is the most probable near-term corpus shift.
- A&D action: **block `aab.sportsontheweb.net`**; alert on HTTP header `X-Supply: 1`. Hunt npm lifecycle script execution against typosquat names; `payload.bin` in `node_modules`; Bun-runtime downloads from `github.com/oven-sh/bun/releases`; IMDS/ECS metadata access from Node processes. Source: [Microsoft MSTIC](https://www.microsoft.com/en-us/security/blog/2026/05/28/typosquatted-npm-packages-used-steal-cloud-ci-cd-secrets/) · Digraph A2 · finding-2026-05-29-0001 · 🔗 **Connects to:** VT-006 Mini Shai-Hulud (lineage suggestion only).
