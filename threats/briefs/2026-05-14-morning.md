## 🔓 Vulnerabilities

**[F5 K000160932 quarterly: 50+ CVEs, headlined by CVE-2026-42945 "NGINX Rift" — heap overflow in the rewrite module, CVSS v4.0 9.2, pre-auth RCE when ASLR is disabled / DoS otherwise.](https://www.securityweek.com/f5-patches-over-50-vulnerabilities/)**
- What: A crafted HTTP request with unnamed PCRE captures plus a question-mark replacement triggers the overflow. Patches across NGINX Plus (R32 P6+, R36 P4+), Open Source (1.30.1 / 1.31.0), Ingress Controller, App Protect WAF. F5 reports no in-the-wild exploitation. Cohort: **CVE-2026-41225** (iControl REST privesc, CVSS 8.6) + **CVE-2026-41957 / 34176 / 39459** (BIG-IP authenticated-RCE).
- Why it matters for A&D: NGINX is the dominant web-tier / reverse-proxy / ingress controller across prime infrastructure. Leverage move: **ASLR-state inventory** — modern Linux defaults ship ASLR enabled (DoS only); legacy / appliance / embedded deployments may not (full pre-auth RCE). The "18-year dormancy" headline is THN + depthfirst editorial — NOT vendor-attested.
- Source: [SecurityWeek (Ionut Arghire)](https://www.securityweek.com/f5-patches-over-50-vulnerabilities/) · [The Hacker News](https://thehackernews.com/2026/05/18-year-old-nginx-rewrite-module-flaw.html) · Digraph: A2 · WEP: very likely (vendor procedural) / likely (no-ITW)
