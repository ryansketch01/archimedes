## What "Azure Local Disconnected Operations" is

Azure Local (formerly Azure Stack HCI / Azure Stack Hub depending
on SKU) is Microsoft's on-premises Azure-equivalent product line.
Azure Local Disconnected Operations specifically supports tenancy
environments that cannot maintain continuous cloud connectivity —
including:

- Sovereign / classified-network deployments
- IL5 / IL6 DoD cloud environments
- Air-gapped or limited-connectivity industrial / OT environments
- ITAR-regulated R&D enclaves where program data cannot egress
  to public cloud
- Tactical / disconnected-edge deployments (military, intelligence,
  remote-operations)

A&D primes per watchlists/aerospace-defense.yaml (Lockheed Martin,
