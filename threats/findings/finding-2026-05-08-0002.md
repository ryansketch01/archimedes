# Ivanti EPMM CVE-2026-6973 — KEV-listed admin-required RCE zero-day, 2026-05-10 remediation deadline, chained-exploitation hypothesis

## Summary

Ivanti disclosed CVE-2026-6973 on 2026-05-07, an improper input
validation flaw in on-prem Endpoint Manager Mobile (EPMM) allowing a
remotely authenticated user with administrative access to achieve remote
code execution. CVSS v3.1 base score 7.2. Ivanti acknowledges "a very
limited number of customers" exploited; CISA added the CVE to KEV the
same day with a 2026-05-10 federal-agency remediation deadline (3-day
window). Patches shipped concurrently with disclosure (12.6.1.1,
12.7.0.1, 12.8.0.1). SecurityWeek follow-on coverage 2026-05-08
introduces a chained-exploitation hypothesis (CVE-2026-6973 may be
chained with prior unauthenticated RCEs CVE-2026-1281 or CVE-2026-1340
to achieve full MDM compromise) and notes that customers who rotated
credentials per January 2026 Ivanti guidance have significantly reduced
risk. Cloud variants (Neurons for MDM, Ivanti EPM, Ivanti Sentry) are
NOT affected — only on-prem EPMM. No tracked-actor attribution.

## Technical detail

CVE-2026-6973 is a post-authentication RCE requiring administrative
credentials on the on-prem EPMM management surface. Cloud variants are
unaffected. The chained-exploitation hypothesis posits that the
admin-auth requirement is reachable by first exploiting one of the
unauthenticated RCEs disclosed in January 2026 (CVE-2026-1281 or
CVE-2026-1340) to obtain admin context, then chaining to CVE-2026-6973
for full MDM compromise. This hypothesis is editorial inference (per
SecurityWeek), not Ivanti-stated.

Defensive context per Ivanti: customers who followed January 2026
guidance to rotate administrative credentials after the
CVE-2026-1281 / CVE-2026-1340 exploitation episode have significantly
reduced risk on CVE-2026-6973 — i.e., even if the prior RCEs were
exploited to obtain admin context, rotated credentials block the
chained pivot.

Shadowserver tracked >850 exposed EPMM IP addresses globally
pre-disclosure (508 Europe, 182 North America); patching status is
unknown post-disclosure.

Same patch bundle includes four non-exploited CVEs:
- CVE-2026-5786 — privilege escalation
- CVE-2026-5787 — certificate theft
- CVE-2026-5788 — arbitrary method invocation
- CVE-2026-7821 — information disclosure
