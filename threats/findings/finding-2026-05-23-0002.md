# Underminr CDN-Tenant-Routing-Bypass — Class-of-Attack Disclosure Affecting ~88M Domains, No CVE, No IOCs

## Summary

SecurityWeek (Ionut Arghire byline) relays a vulnerability-class disclosure from ADAMnetworks (CEO David Redekop named-byline) on 2026-05-23 describing "Underminr," a domain-fronting variant in which an attacker presents SNI and HTTP Host header values of a legitimate domain while forcing the TCP connection to a different tenant's IP on the same shared CDN edge. ADAMnetworks claims approximately 88 million domains affected with US/UK/Canada geographic concentration and observed real-world abuse against large-scale hosting providers. ## Technical detail

**Mechanism (per ADAMnetworks via SecurityWeek)**
- SNI (Server Name Indication) value presents a legitimate domain
- HTTP Host header presents the same legitimate domain
- TCP connection routes to a different tenant's IP on the same shared CDN edge
- Root cause framed as: DNS decisions, edge IPs, SNI, Host headers, and CDN tenant routing are not correlated

**Scope (per ADAMnetworks; methodology not disclosed)**
- Approximately 88 million domains affected
- Geographic concentration: US, UK, Canada internet infrastructure
- Attack vectors observed: TCP connections on port 443; malicious applications, shell scripts, and ClickFix attacks

**Exploitation status**
- SecurityWeek confirms "real-world abuse" attribution to ADAMnetworks
- ADAMnetworks attests to abuse against "large-scale hosting providers"
- NO named threat actor
- NO quantified telemetry on observed-abuse scale

**Vendor coordination — verifiable absences**
- NO CVE assignment
- NO named affected CDN providers (Akamai / Cloudflare / Fastly / AWS CloudFront / Azure Front Door)
- NO patch or mitigation details
- NO coordinated-disclosure timeline
