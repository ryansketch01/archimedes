# Microsoft acknowledges Windows Update failures in restricted Windows networks (air-gapped + firewalled) — January 2026 preview update regression — KIR workaround

## Summary

BleepingComputer relays Microsoft's self-disclosure that Windows Update failures are occurring across restricted network environments — including air-gapped and firewalled systems — for customers who installed the January 2026 optional non-security preview updates. The affected updates are KB5083806 (Windows 11 26H1) and KB5083631 (Windows 11 24H2 / 25H2 / Windows Server 2025). The error surfaced is 0x80010002. Microsoft attributes the root cause to changes in download timeout requirements introduced by the January preview updates; affected systems can download February updates but fail on March 2026 and later releases. Microsoft frames the issue as a download-reliability bug, not a device-integrity or update-installation bug. Microsoft directs affected administrators to deploy Known Issue Rollback (KIR) group policies via provided MSI files; client devices require restart after policy application. No A&D-prime, federal agency, classified, secure-enclave, or CMMC-regulated customer is explicitly named in either the BleepingComputer piece or in Microsoft's own framing.
