# CISA KEV adds two actively-exploited Joomla page-builder unauth-RCE CVEs (CVE-2026-48908, CVE-2026-56290)

## Summary

CISA added two Joomla CMS page-builder extension CVEs to the KEV catalog on 2026-07-07, confirming active in-the-wild exploitation. Both are unauthenticated file-upload-to-RCE flaws (CWE-434) rated CVSS 9.8 (v3.1) / 10.0 (v4.0). The active-exploitation determination rests solely on CISA KEV; NVD corroborates the CVE facts but not exploitation, so the finding is capped at A2/likely by the single-source veto. Aerospace/defense relevance is negligible — these are website-CMS plugins with no material industrial-base deployment pathway — so the disposition is a morning KEV-roundup line, not a standalone FLASH.

## Technical detail

- **CVE-2026-48908** — JoomShaper SP Page Builder extension for Joomla (1.0.0–6.6.1; fixed 6.6.2). Unrestricted upload of file with dangerous type (CWE-434) enabling upload and execution of PHP code. CVSS v3.1 9.8 / v4.0 10.0, vector `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`.
- **CVE-2026-56290** — Joomlack Page Builder CK extension for Joomla (1.0–3.6.0). Improper access control → unauthenticated arbitrary file upload → RCE (CWE-434). CVSS v3.1 9.8 / v4.0 10.0, same PR:N unauthenticated vector.
- Both are patched-but-actively-exploited (standard KEV profile), not zero-days-without-patch. `knownRansomwareCampaignUse: Unknown` for both.
- References: NVD (per-CVE), MITRE CWE-434.
