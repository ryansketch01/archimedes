# Mini Shai-Hulud npm/PyPI worm — TeamPCP (#001 HIGH) — first documented validly-attested supply-chain worm; 169-172 packages compromised

## Summary

Wiz Research, Snyk, and StepSecurity attribute a 2026-05-11–05-12 npm and PyPI supply-chain compromise to TeamPCP (Archimedes roster #001 HIGH), the same actor cluster behind the 2026-05-04 PyTorch Lightning ShaiWorm and the 2026-05-11 Checkmarx Jenkins plugin compromise. The campaign — branded "Mini Shai-Hulud" — compromised 169–172 npm packages across 403 malicious versions in a 48-hour window, spanning @tanstack (42 packages / 84 versions), @uipath, @mistralai, @opensearch-project, @squawk (19 aviation data packages), @tallyui, and DraftLab namespaces, plus PyPI packages guardrails-ai@0.10.1 and mistralai@2.4.6. CVE-2026-45321 (CVSS 9.6) and GHSA-g7cv-rxg3-hmpx were assigned to the TanStack compromise. Per Wiz, Snyk, and StepSecurity, the worm hijacks legitimate maintainer OIDC tokens mid-workflow to publish packages that carry SLSA provenance signatures — Wiz characterizes this as the first publicly documented npm worm producing validly-attested malicious packages, breaking the SLSA attestation assurance model.

Procedural facts (CVE, packages, IOCs, GHSA, dual-ecosystem worm propagation) carry WEP very_likely with multi-source independent corroboration. TeamPCP attribution and the novelty/SLSA-breaking claim carry WEP likely under conservative grading on attribution-independence depth.

## Technical detail

### CVE and advisory

- CVE-2026-45321 (CVSS 9.6 CRITICAL) — supply-chain compromise via validly-attested malicious packages
- GHSA-g7cv-rxg3-hmpx — published
- Patch status: package versions reverted by maintainer (TanStack reverted same-day); not a vendor-issued product patch

### Worm mechanism

Per Wiz and Snyk:

1. Attacker compromises legitimate maintainer's GitHub Actions OIDC token mid-workflow (initial access vector not yet fully characterized — under analysis)
2. Worm enumerates every package the compromised maintainer publishes
3. Worm injects the same payload into each package
4. Worm publishes via the hijacked OIDC token, which produces SLSA provenance attestations on the malicious versions
5. SLSA-attested malicious packages bypass attestation-based supply-chain assurance models

This is the first publicly documented case of malicious packages carrying valid SLSA provenance signatures. Prior Shai-Hulud variants (PyTorch Lightning ShaiWorm 2026-05-04; Shai-Hulud 2.0 December 2025) were attestation-naive.

### Country-aware termination

Inherited from Shai-Hulud family lineage: malware checks for Russian-language system locale and terminates without exfiltration if detected.

### Dual-ecosystem propagation

Per Snyk + Wiz: 172 packages / 403 malicious versions across npm AND PyPI within hours of initial compromise. Prior Shai-Hulud generations were single-ecosystem (PyPI for ShaiWorm 2026-05-04; npm for Shai-Hulud 2.0 December 2025).
