## 🔓 Vulnerabilities

**UPDATE: Microsoft patches RoguePlanet out-of-band and assigns CVE-2026-50656 — Nightmare Eclipse series now fully closed**
- What: Microsoft shipped an out-of-band fix for the RoguePlanet Defender zero-day (tracked [VT-011](../vulnerabilities/RoguePlanet/profile.md)) via Malware Protection Engine update 1.1.26060.3008, and assigned it [CVE-2026-50656](../vulnerabilities/RoguePlanet/profile.md). The engine update auto-deploys through the same channel as the earlier BlueHammer fix — no KB action required. RoguePlanet was a TOCTOU race-condition escalation to SYSTEM on fully-patched Windows 10/11.
- Why it matters for A&D: Defender is the default endpoint protection across primes and Tier-1/2 suppliers; RoguePlanet was the last open tool in the series and a standard-user-to-SYSTEM precursor. This is risk reduction, not new exposure. The six earlier siblings were already patched — with RoguePlanet closed, the series is fully closed.
- Read honestly: BleepingComputer and SecurityWeek both relay the same Microsoft action — two bylines, one evidence basis. Single-source veto holds the assessment at likely. The CVE assignment restores KEV-eligibility (RoguePlanet previously lacked a CVE); no KEV listing observed as of this morning's sweep. No in-the-wild exploitation is attributed to RoguePlanet specifically.
- Source: [BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-patches-rogueplanet-defender-zero-day-vulnerability/) · Digraph: A2 · WEP: likely
- Related: [VT-011 / CVE-2026-50656](../vulnerabilities/RoguePlanet/profile.md)
- 🔗 **Update on:** VT-011 RoguePlanet — status moves from "no CVE, unpatched, KEV-ineligible, last open series tool" to "CVE assigned, patched out-of-band, series closed."

**GhostLock (CVE-2026-43499) — 15-year-old Linux kernel use-after-free, root LPE and container escape, patched April 2026**
- What: Nebula Security disclosed GhostLock via Google's kernelCTF program — a use-after-free in the kernel's task-prioritization cleanup path enabling privilege escalation to root and container escape. Introduced in kernel 2.6.39 (2011); present in every major distribution since. The fix has shipped since April 2026 — an n-day, not a fresh zero-day. No in-the-wild exploitation; the demonstration ran inside Google's research program.
- Why it matters for A&D: structural, not active. A ubiquitous Linux-kernel root-LPE and container-escape maps to DIB Linux workstation, build-farm, and CI/CD container estates — the same escalation-primitive class as the Windows Nightmare Eclipse series. No named A&D victim, no sector targeting, no actor. Confirm April-2026 patch adoption across Linux fleets; the risk is a patched-but-unpatched-in-practice gap, not a live exploit.
- Read honestly: single SecurityWeek relay of the Nebula/kernelCTF disclosure; single-source veto caps the assessment at likely. CVSS and the exact fixed-version boundary were not published — flagged to vuln-tracker for NVD enrichment and a new tracking entry.
- Source: [SecurityWeek](https://www.securityweek.com/15-year-old-linux-vulnerability-ghostlock-earns-researchers-92k-from-google/) · Digraph: B2 · WEP: likely
- Related: CVE-2026-43499 (net-new; flagged for vuln-tracker addition)
