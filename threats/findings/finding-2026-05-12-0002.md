# Siemens May 2026 Patch Tuesday — Five CVEs Across RUGGEDCOM ROX, ROS# Robotics Library, and SIMATIC Cluster; ROS# Unauthenticated Path Traversal Is The Headliner

## Summary

Siemens ProductCERT published its May 2026 Patch Tuesday cluster on
2026-05-12, disclosing five CVEs across three product families. The
headliner is CVE-2026-41551 (SSA-357982): an UNAUTHENTICATED CVSS 9.1
v3.1 / 9.3 v4.0 path traversal in the ROS# .NET library for the Robot
Operating System, with arbitrary file read AND write impact. The
near-headliner is CVE-2025-40949 (SSA-081142): a CVSS 9.1
AUTHENTICATED command injection in the RUGGEDCOM ROX Scheduler Web
UI affecting 11 ruggedized industrial-networking models, with
root-level arbitrary command execution. Three SIMATIC CVEs round out
the cluster (CVE-2026-22924 CN 4100 resource exhaustion 8.8; CVE-2026-25786
and CVE-2026-25787 stored XSS pair 9.1 each via PLC station name /
Technology Object name on administrative web pages). Siemens states
no in-the-wild exploitation observed and all five are patched at
disclosure. No specific A&D prime is named.

## Technical detail

### CVE-2026-41551 (SSA-357982) — ROS# path traversal (HEADLINER)

- Product: ROS# (Siemens' .NET library for the Robot Operating
  System); all versions before V2.2.2
- Vulnerability mechanism: Path traversal in `file_server` component
  due to unsanitized user input (CWE-23 Relative Path Traversal)
- Impact: Remote attacker arbitrary file read AND write on device
  with service-user privileges
- CVSS: 9.1 CRITICAL (v3.1) / 9.3 CRITICAL (v4.0)
- Attack vector: Network
- Authentication required: NONE (UNAUTHENTICATED)
- User interaction: None
- Patch: v2.2.2 available at
  https://github.com/siemens/ros-sharp/releases/tag/2.2.2
- Pre-patch mitigations (per Siemens): trusted-network-only
  deployment; minimal user permissions; URDF-transfer-only use; no
  continuous background-service operation

**Why headliner:** Unauthenticated network-vector file-read-AND-write
on a robotics library is unusual for the Siemens advisory shape
(most ICS advisories require authentication). ROS is the dominant
open-source robotics middleware; ROS# is its primary .NET interop
layer. Aerospace/defense robotics R&D contexts include military UGV
(unmanned ground vehicle) and UAV ground control, collaborative
robotics in defense manufacturing, and simulation tooling.

### CVE-2025-40949 (SSA-081142) — RUGGEDCOM ROX command injection (near-headliner)

- Product: RUGGEDCOM ROX II family — 11 affected models below
  V2.17.1: MX5000, MX5000RE, RX1400, RX1500, RX1501, RX1510, RX1511,
  RX1512, RX1524, RX1536, RX5000
- Vulnerability mechanism: Scheduler functionality in Web UI does
  not properly sanitize user-supplied input (CWE-78 OS Command
  Injection)
- Impact: Authenticated attacker arbitrary command execution with
  root privileges
- CVSS: 9.1 CRITICAL (v3.1) / 8.9 HIGH (v4.0)
- Attack vector: Network
- Attack complexity: Low
- Authentication required: HIGH (PR:H — authenticated)
- Patch: v2.17.1+
- Critical-infrastructure context (per Siemens): RUGGEDCOM Ethernet
  switches operate in "electrical harsh and climatically demanding
  environments such as electric utility substations and traffic
  control cabinets" — also deployed in defense ground systems and
  military substation contexts.
