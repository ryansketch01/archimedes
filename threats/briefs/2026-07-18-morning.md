## 🔓 Vulnerabilities

**KEV deadline tracker — three actively-exploited CVEs due this weekend.** No new exploitation escalation, atomic IOC, actor attribution, or A&D-victim disclosure across the three this window. The deadlines are the development; full technical detail sits in prior briefs and the linked dossiers.

**UPDATE: Oracle EBS CVE-2026-46817 remediation deadline lands today (2026-07-18).**
- What: unauthenticated Oracle Payments / File Transmission takeover, CVSS 9.8, actively exploited since ~2026-06-27. n-day — patched in Oracle's May 2026 Critical Patch Update.
- Why it matters for A&D: EBS is pervasive ERP across the DIB; the accelerated ~3-day BOD 26-04 deadline closes today. Confirm EBS 12.2 instances are patched.
- Source: [CISA KEV catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) · Digraph: A2 · Vuln: [CVE-2026-46817](../vulnerabilities/CVE-2026-46817/profile.md) (VT-043)

**SharePoint on-prem CVE-2026-58644 + FortiSandbox CVE-2026-25089 / CVE-2026-39808 — due tomorrow (2026-07-19).**
- SharePoint: unauthenticated deserialization RCE, CVSS 9.8, Server 2016/2019/SE only (not SharePoint Online/M365). Quiet since Rapid7's 2026-07-17 corroboration.
- FortiSandbox: OS command injection, actively exploited and KEV-listed. Quiet this window.
- Why it matters for A&D: on-prem SharePoint and Fortinet security appliances are common in DIB estates — close both out before tomorrow's deadline.
- Source: [CISA KEV catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) · Digraph: A2 · Vulns: [CVE-2026-58644](../vulnerabilities/CVE-2026-58644/profile.md) (VT-041), [CVE-2026-25089](../vulnerabilities/CVE-2026-25089/profile.md) (VT-045), [CVE-2026-39808](../vulnerabilities/CVE-2026-39808/profile.md) (VT-046)

**Rapid7 discloses "wp2shell" — a critical unauthenticated RCE in WordPress Core, patched, no exploitation yet.**
- What: CVE-2026-63030, an unauthenticated RCE via the WordPress Core REST API batch endpoint on a default install (NVD 9.8 critical; CWE-436 route confusion). Fixed in 6.9.5 / 7.0.2.
- Status: no in-the-wild exploitation and no public PoC as of 2026-07-17; Rapid7 assesses a public PoC is **likely** to appear soon. One disclosure chain (Rapid7 + NVD + GHSA), so graded A2 / likely with the single-source veto applied.
- Why it matters for A&D: structural only. WordPress is public-web/marketing-site tier — a prime running it carries the same generic internet-facing exposure any org does, not an A&D-specific targeting signal. Patch WordPress estates; watch for a PoC drop.
- Source: [Rapid7 ETR](https://www.rapid7.com/blog/post/etr-cve-2026-63030-wp2shell-a-critical-remote-code-execution-vulnerability-in-wordpress-core) · Digraph: A2 · Vuln: CVE-2026-63030 (net-new — not yet in the vulnerability index; watch-keyword entry recommended)
