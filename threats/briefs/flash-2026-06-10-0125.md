[CVE-2026-50751](https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json) — Check Point Remote Access VPN, CVSS 9.3, KEV deadline 2026-06-11 (T-1).** Unauthenticated bypass in Remote Access VPN + Mobile Access deployments running deprecated IKEv1. Patched at disclosure 2026-06-08; exploitation observed since 2026-05-07 (32 days pre-patch — true zero-day). [Check Point links exploitation to a Qilin ransomware affiliate](https://www.bleepingcomputer.com/news/security/check-point-links-vpn-zero-day-attacks-to-qilin-ransomware-gang/) — single-source vendor IR; attribution capped at "likely." DIB perimeter exposure: likely (architectural; IKEv1 default-on prevalence unmeasured). **Action.** Patch *today*; if change-control can't land before T-0, disable IKEv1 per vendor workaround; hunt 60-day VPN logs for unauthenticated IKEv1 session anomalies.

**2. [CVE-2026-11645](https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json) — Chromium V8 OOB read/write zero-day, KEV deadline 2026-06-23 (T-13).** [Google emergency Chrome update](https://thehackernews.com/2026/06/chrome-v8-zero-day-cve-2026-11645.html) 2026-06-09 — fifth Chrome zero-day of 2026 per The Hacker News. A&D workstation exposure is architectural (Chromium ships everywhere), not A&D-specific targeting. **Action.** Push the Chrome / Edge update *this week*; flag embedded-WebView and Electron apps (CAD viewers, contract portals) for separate audit — those lag the browser patch cycle by weeks.

**3. [CVE-2026-42271](https://thehackernews.com/2026/06/litellm-flaw-cve-2026-42271-exploited.html) — BerriAI LiteLLM, KEV 2026-06-08, patch 1.83.7+.** CISA confirmed standalone ITW exploitation of an authenticated command-injection flaw (CVSS 8.7) affecting LiteLLM >=1.74.2 and <1.83.7. Patch imperative stands on the standalone KEV alone. Second LiteLLM KEV add in 31 days (after CVE-2026-42208 SQLi 2026-05-08) — pattern flagged to vuln-tracker. **Action.** Inventory LiteLLM behind any internal-AI gateway; patch to 1.83.7+ *by EOD*; verify Starlette sits behind an auth proxy.
