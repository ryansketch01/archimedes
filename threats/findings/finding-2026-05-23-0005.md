# Packagist Supply-Chain Attack — 8 Composer Packages, Cross-Ecosystem package.json Postinstall Injection, GitHub-Hosted Linux Payload, UNATTRIBUTED

## Summary

Socket originating research, relayed by The Hacker News (Ravie Lakshmanan byline) on 2026-05-23, documents a coordinated supply-chain attack against eight Composer/Packagist packages. The malicious code is injected into `package.json` postinstall hooks rather than `composer.json`, exploiting cross-ecosystem placement to bypass PHP dependency scanners focused on Composer metadata. The hook downloads a Linux binary (`gvfsd-network`, mimicking the GNOME Virtual File System daemon) from a GitHub Releases URL at `github[.]com/parikhpreyash4/systemd-network-helper-aa5c751f`, drops it to `/tmp/.sshd`, applies executable permissions, runs in background, and disables TLS verification. Socket found references to the same payload across 777 GitHub files, suggesting broader campaign scope beyond the eight named Composer packages. The `parikhpreyash4` GitHub account is disabled. Socket explicitly declines attribution; Archimedes preserves that posture per Hard Rule 2.
