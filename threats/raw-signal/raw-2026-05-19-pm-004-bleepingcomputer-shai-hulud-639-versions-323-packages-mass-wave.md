# New Shai-Hulud malware wave compromises 600 npm packages

BleepingComputer (Bill Toulas) — Tuesday 2026-05-19, 10:30 EDT (14:30 UTC).

## Source primary content (extract — preserved for grader)

Per the BleepingComputer primary:
- **639 malicious versions** were published across **323 unique npm packages** in approximately one hour on 2026-05-19, 01:56–02:56 UTC (21:56–22:56 EDT 2026-05-18 — actually inside this window in window-edge from the morning brief, but published-detail just past morning-brief publication time and surfaced via BleepingComputer relay 10:30 EDT this afternoon)
- The threat actors initially compromised the npm account `atool`, which publishes `@antv` namespace packages — this corroborates and extends the morning raw-signal am-008 (THN @antv 323-package compromise via atool maintainer)
- Notable compromised packages: `echarts-for-react`, `@antv/g2`, `@antv/g6`, `@antv/l7`, `timeago.js`, `jest-canvas-mock` (described as "had not received a legitimate update for a long time")
- **~2,900 malicious GitHub repositories** were generated by this campaign
- Rogue repositories contain README files with the marker `"niaga og ew ereh :duluh-iahs"` (reverse of "Shai-Hulud: Here We Go Again")

**Tradecraft (per Socket / Endor Labs / Aikido Security / StepSecurity / Microsoft collectively):**
- Stolen data is serialized, Gzip-compressed, **AES-256-GCM-encrypted**, and **RSA-OAEP-wrapped** to make network inspection harder
- Generates valid **Sigstore provenance attestations** by **abusing OpenID Connect (OIDC) tokens**, enabling packages to appear legitimately signed
- Persistence mechanisms include **backdoors planted in VS Code and Claude Code configurations**
- Targets developer workstations and CI/CD environments including GitHub Actions, GitLab CI, Jenkins, Azure DevOps, CircleCI, Vercel, Netlify

**Credentials stolen:**
- GitHub
- npm
- Cloud (AWS / Azure / GCP)
- Kubernetes
- Vault
- Docker
- Database credentials
- SSH keys

**Exfiltration infrastructure:**
- Primary exfil: `filev2.getsession[.]org/file/` via Session P2P network
- Credential shipping endpoint: `t.m-kosche.com` (per Microsoft attribution)

**Attribution language (verbatim per source):**
"Attribution of the new Shai-Hulud campaign is more difficult" due to the malware code "being recently leaked on GitHub by the TeamPCP threat group." The payload was "subsequently already been used in attacks," complicating origin determination.

**Researcher sources:**
