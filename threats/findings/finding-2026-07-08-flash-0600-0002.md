# CISA KEV adds Langflow CVE-2026-55255 — authenticated IDOR, active exploitation, CVSS 8.4 (below FLASH floor)

## Summary

CISA added CVE-2026-55255 to the KEV catalog on 2026-07-07, confirming active in-the-wild exploitation of an authenticated IDOR / authorization-bypass flaw (CWE-639) in the Langflow AI-agent-builder framework. CVSS is 8.4 — below the 9.0 FLASH Trigger 1 floor — and the flaw requires authentication (PR:L), so it is a graded finding but not a FLASH. Exploitation rests solely on CISA KEV (BleepingComputer relays the same event; NVD does not attest exploitation), capping the finding at A2/likely under the single-source veto. Route to the morning KEV-roundup.

## Technical detail

- **CVE-2026-55255** — Insecure Direct Object Reference / authorization bypass through user-controlled key (CWE-639) in the `/api/v1/responses` endpoint; an authenticated attacker can execute any flow belonging to another user by specifying the victim's flow ID.
- CVSS v3.1 8.4 (HIGH), vector `CVSS:3.1/AV:N/AC:H/PR:L/UI:N/S:C/C:H/I:H/A:L` — note PR:L (authenticated) and AC:H. Not pre-auth; scores below 9.0.
- Affected: Langflow before 1.9.2. Patch available (>=1.9.2). `knownRansomwareCampaignUse: Unknown`.
- References: NVD, MITRE CWE-639.
