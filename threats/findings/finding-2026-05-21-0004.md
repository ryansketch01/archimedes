# Drupal SA-CORE-2026-004 — CVE-2026-9082 PostgreSQL SQLi in core database abstraction API (CVSS 6.5, Highly Critical 20/25, anonymous-attacker exploitable, patches available)

## Summary

Drupal Security Team published SA-CORE-2026-004 on 2026-05-20
(within the pre-announced 17:00-21:00 UTC patch window from
PSA-2026-05-18), assigning CVE-2026-9082 to a PostgreSQL-specific
SQL injection in the Drupal core database abstraction API. CVSS 6.5
per NVD / CISA-ADP / CVE.org consistent; Drupal internal "Highly
Critical 20/25" rating (rare top-tier classification). Anonymous
unauthenticated attackers can trigger information disclosure /
privilege escalation / RCE. PostgreSQL-only database scope
materially reduces effective attack surface. Patches in Drupal
11.3.10 / 11.2.12 / 11.1.10 / 10.6.9 / 10.5.10 / 10.4.10; manual
hotfixes for EOL Drupal 9.5 and 8.9; Drupal 7 unaffected. No
active exploitation reported at release. No actor attributed.

## Technical detail

- CVSS v3.1: **6.5 MEDIUM** (per NVD / CISA-ADP / CVE.org)
- Vector: AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:N
- CWE-89 SQL injection (database abstraction API)

**Attack characteristics:**
- Anonymous (unauthenticated) attacker
- Network-reachable
- PostgreSQL-specific (MySQL/MariaDB/SQLite/SQL Server unaffected

- Impact range per Drupal Security Team: information disclosure /
  privilege escalation / RCE

**Affected versions:**
- Drupal 11.0.x through 11.3.x
- Drupal 10.4.x through 10.6.x and below
- Drupal 9.x and 8.x (EOL — manual hotfixes provided for 9.5 + 8.9)

- Drupal 11.3.10, 11.2.12, 11.1.10
- Drupal 10.6.9, 10.5.10, 10.4.10
- Manual patches for Drupal 9.5 and 8.9

### CVSS-vs-vendor-severity gap

The CVSS 6.5 (MEDIUM) score and the Drupal internal "Highly
Critical 20/25" rating diverge because Drupal's taxonomy is anchored
on anonymous-attacker reachability + impact range, not CVSS
directly. CVSS 6.5 reflects the low-CIA base scoring (low-confidentiality,
low-integrity, no-availability); Drupal's "Highly Critical 20/25"
reflects the unauthenticated-attacker + impact-range-up-to-RCE
operational interpretation. The PSA-2026-05-18 pre-coverage framing
("threat actors might develop exploits within hours of the update
disclosure") is consistent with the historical Drupalgeddon pattern.

## A&D-prime relevance — MODEST

Drupal is a content management system used at the web-presence
layer. A&D-prime customer-facing sites (corporate sites, careers
sites, investor-relations sites) and partner-portal applications
may run Drupal. PostgreSQL-specific narrowing further reduces the
at-risk subset (MySQL/MariaDB is more common at the enterprise
tier).

Critical-infrastructure / OT / ITAR-regulated R&D environments do
not typically run public Drupal. Modest A&D-prime exposure overall;
patch-application priority should follow general CMS-update cadence
rather than emergency-patch cadence given the CVSS 6.5 + PostgreSQL-
specific + patches-available combination.
