# Microsoft May 2026 Patch Tuesday — 137 CVEs, 17+ Criticals Including Windows DNS Client RCE and Word Preview-Pane RCE Pair; No Zero-Days, No ITW Exploitation

## Summary

Microsoft published its May 2026 Patch Tuesday on 2026-05-12, addressing
**137 total vulnerabilities** (120 Windows-only + 17 Edge/Chromium
cumulative). The batch contains **17+ Critical-severity** CVEs spanning
Windows infrastructure (DNS Client, Netlogon, Hyper-V, GDI, Graphics
Component, Native WiFi Miniport), productivity suite (Office, Word
preview-pane RCE pair, SharePoint, Dynamics 365 on-premises), identity
(SSO Plugin for Jira & Confluence), and AI surface (M365 Copilot
information disclosure). Microsoft explicitly states **no zero-days
disclosed and none of the flaws have been flagged as exploited in the
wild**. All CVEs are patched at-disclosure. BleepingComputer's Lawrence
Abrams flags **CVE-2026-41096 (Windows DNS Client RCE)** as the most
operationally significant given the universality of the affected
surface; SecurityWeek's Ionut Arghire flags **CVE-2026-40364 + CVE-2026-
40361 (Word RCE pair)** as preview-pane-exploitable. No A&D prime is
named in the advisory.

## Technical detail

### CVE-2026-41096 — Windows DNS Client RCE (HEADLINER per BleepingComputer)

- Product: Windows DNS Client
- Class: Remote Code Execution via memory corruption on attacker-
  controlled DNS response
- Severity: Critical
- Attack vector: Network (attacker-controlled DNS server sends
  specially crafted DNS response triggering memory corruption + RCE)
- ITW exploitation: not reported by Microsoft at patch time
- Why headliner: DNS resolution is a fundamental infrastructure layer
  running on every domain-joined Windows endpoint. Any working PoC
  would generate immediate detection content; the affected surface is
  effectively universal across A&D prime Windows fleets.

### CVE-2026-40364 + CVE-2026-40361 — Word RCE pair (HEADLINER per SecurityWeek)

- Product: Microsoft Word
- Class: CVE-2026-40364 type-confusion RCE; CVE-2026-40361 use-after-
  free RCE
- Severity: High (CVSS v3 8.4 each per SecurityWeek)
- Attack vector: SecurityWeek states "exploitation is possible just by
  viewing a malicious document in the Preview Pane" — no user click
  required beyond receiving the message that lands in Outlook with
  Preview Pane enabled (common enterprise default).
- ITW exploitation: not reported by Microsoft at patch time
- Why notable: Word preview-pane RCE class historically draws active
  exploitation within weeks (CVE-2017-11882 EQNEDT32, CVE-2021-40444
  MSHTML, CVE-2023-23397 Outlook NTLM precedents).

### CVE-2026-41089 — Windows Netlogon RCE

- Product: Windows Netlogon (Active Directory authentication service)
- Class: Remote Code Execution
- Severity: Critical
- ITW exploitation: not reported by Microsoft at patch time
- Why notable: Netlogon RCE class has historical exploitation precedent
  (Zerologon CVE-2020-1472); remote-vector RCE in this path catalyzes
  rapid PoC publication.

### CVE-2026-40365 — SharePoint Server RCE

- Product: Microsoft SharePoint Server
- Class: Remote Code Execution; attack vector authenticated network-
  based per BleepingComputer
- Severity: Critical
- ITW exploitation: not reported

### CVE-2026-41103 — Microsoft SSO Plugin for Jira & Confluence elevation

- Product: Microsoft SSO Plugin for Jira & Confluence (Atlassian-
  ecosystem identity integration)
- Class: Elevation of Privilege
- Severity: Critical
- ITW exploitation: not reported
- Why notable: DevOps and program-management surface at primes; SSO
  plugin EoP could enable lateral movement into identity infrastructure.

### CVE-2026-42898 — Dynamics 365 on-premises RCE

- Product: Microsoft Dynamics 365 (on-premises)
- Class: Remote Code Execution
- Severity: Critical
- ITW exploitation: not reported
- Why notable: CRM + supply-chain ERP adjacency at multiple primes.

### CVE-2026-40402 — Windows Hyper-V elevation

- Product: Windows Hyper-V
- Class: Elevation of Privilege (guest-to-host boundary)
- Severity: Critical
- ITW exploitation: not reported

### CVE-2026-26164 — Microsoft 365 Copilot information disclosure

- Product: Microsoft 365 Copilot
- Class: Information Disclosure
- Severity: Critical
- ITW exploitation: not reported
- Why notable: AI-surface information-disclosure class is novel;
  consequence model less well-established than traditional RCE/EoP.
