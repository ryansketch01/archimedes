# SEPPMail Secure E-Mail Gateway seven-CVE cluster — CVSS up to 10.0 — patched 15.0.2.1 / 15.0.3 / 15.0.4 — InfoGuard Labs originating — no in-the-wild

## Summary

The Hacker News relays InfoGuard Labs (researchers Dario Weiss, Manuel Feifel, Olivier Becker) originating disclosure of seven net-new CVEs in SEPPMail Secure E-Mail Gateway, a Swiss enterprise email-security virtual appliance. The cluster includes CVE-2026-2743 (CVSS 10.0 LFT path-traversal arbitrary file write enabling RCE), CVE-2026-44126 (CVSS 9.2 deserialization RCE), CVE-2026-44128 (CVSS 9.3 Perl eval injection), CVE-2026-44125 (CVSS 9.3 missing authorization in GINA UI), CVE-2026-44127 (CVSS 8.8 unauthenticated path traversal in attachment preview), CVE-2026-44129 (CVSS 8.3 template engine injection), and CVE-2026-7864 (CVSS 6.9 information disclosure). InfoGuard's theoretical attack scenario chains CVE-2026-2743 with syslog-configuration overwrite to obtain a Perl-based reverse shell with complete appliance takeover and mail-traffic-read access. All seven CVEs are PATCHED at disclosure in versions 15.0.2.1 (CVE-2026-44128), 15.0.3 (CVE-2026-44126), and 15.0.4 (remaining). No in-the-wild exploitation is documented. No tracked actor named. No named A&D-prime customer.
