# Morning Brief — 2026-07-13

**NSA, FBI, CISA and 15 allied agencies warn that Russia's FSB Center 16 (Berserk Bear) is pulling configuration files off poorly-secured routers via Cisco Smart Install — CVE-2018-0171, CVSS 9.8, exploited since November 2021 — with the defense industrial base named among seven targeted sectors.**

**Why it matters:** Any DIB edge or branch router running Smart Install (TCP 4786) or default/weak SNMP is the exposure — and the fix is a config audit you can run today, one that stands without a single atomic IOC.

## 🚨 Active Threats

**[18-agency joint advisory — Russia's FSB Center 16 harvests router configs via Cisco Smart Install (CVE-2018-0171)](https://www.bleepingcomputer.com/news/security/us-and-allies-share-defense-tips-against-russian-hackers-targeting-critical-infrastructure/)**

- What: NSA, FBI, CISA and 15 partner agencies (eight nations) warned that FSB Center 16 — vendor-tracked as Berserk Bear / Dragonfly / Static Tundra, not on the roster — scans routers for default/weak SNMP, uses spoofed-IP commands to pull device configs, and exfiltrates via TFTP, exploiting Cisco Smart Install (CVE-2018-0171). It restates a known campaign the FBI flagged in August 2025.
- Why it matters for A&D: Generic-critical-infra, not defense-specific — the DIB is one of seven named sectors. But stolen router configs feed credential harvest and deeper access.
- Action: Audit Cisco IOS / IOS XE devices for Smart Install with TCP 4786 reachable; disable it and harden SNMP. A -30d Splunk sweep for the CVE / port 4786 / SNMP returned zero hits — silence that does not confirm a clean estate (Hard Rule 8).
- Source: [BleepingComputer](https://www.bleepingcomputer.com/news/security/us-and-allies-share-defense-tips-against-russian-hackers-targeting-critical-infrastructure/) · Digraph: A2 · WEP (ongoing campaign): likely
