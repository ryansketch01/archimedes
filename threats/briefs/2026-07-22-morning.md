# Morning Brief — 2026-07-22

**Attackers are actively exploiting a net-new on-prem SharePoint flaw, [CVE-2026-50522](../vulnerabilities/CVE-2026-50522/profile.md), to steal machine keys and forge authentication tokens that survive patching — NVD confirms the flaw unauthenticated (PR:N) at CVSS 9.8.**

**Why it matters:** On-prem SharePoint is pervasive across the defense industrial base, including classified-adjacent enclaves; a pre-auth machine-key theft hands an attacker forged-token persistence that outlasts the patch, so patching alone will not evict a foothold.

---

## 🚨 Active Threats

**Net-new on-prem SharePoint RCE [CVE-2026-50522](../vulnerabilities/CVE-2026-50522/profile.md) actively exploited for machine-key theft**
- WatchTowr honeypots confirmed exploitation July 20–21, within hours of a public PoC; Defused observed related activity as early as July 17. The deserialization flaw (CWE-502) yields code execution and machine-key theft, which — per WatchTowr's analysis — forges authentication tokens that persist across the patch.
- **Vector confirmed unauthenticated.** NVD (status "Analyzed") carries PR:N, CVSS 9.8 — the full internet-exposed on-prem SharePoint estate is in scope. SecurityWeek's earlier authenticated-Site-Owner characterization is contradicted by the primary and does not narrow the exposed population.
- **A&D relevance is structural**, not a targeted campaign: on-prem SharePoint is DIB-pervasive, but no A&D or DIB victim was named and no actor was attributed by any source.
- **Action:** Apply Microsoft's July 14, 2026 security update (fixed builds in the dossier). Patching alone is insufficient — rotate machine keys on any exposed asset, because stolen keys forge tokens that survive the update.
- Exploitation is graded **likely**, not confirmed at scale: two publishers (BleepingComputer, SecurityWeek) rest on a single evidence basis (WatchTowr + Defused honeypot telemetry).
- First-party Splunk is clean this cycle — 0 tracked-IOC hits, and no atomic network IOCs were published to hunt on. Visibility-bounded, non-disconfirming.
- Not on CISA KEV as of catalog v2026.07.21. This is the strongest rapid-KEV candidate in the corpus (unauthenticated vector + in-the-wild use + public PoC); a KEV listing would be a state change worth watching.
- Source: [BleepingComputer](https://www.bleepingcomputer.com/news/security/critical-sharepoint-rce-flaw-exploited-to-steal-machine-keys/) · Digraph: B2 (single-source veto; no actor attributed) · [VT-048 / CVE-2026-50522](../vulnerabilities/CVE-2026-50522/profile.md).
