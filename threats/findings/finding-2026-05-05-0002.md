# CrowdStrike + Microsoft: Charming Kitten / Mint Sandstorm Q2 2026 credential-harvest campaign vs. defense-policy think tanks

## Summary

CrowdStrike and Microsoft MSTIC published concurrent 2026-05-04 reports attributing a February–April 2026 credential-harvest campaign to Charming Kitten (Microsoft alias: Mint Sandstorm; roster ID 011; IRGC-IO). Operators impersonated Brookings, RUSI, and Atlantic Council researchers in tailored "comment on a paper draft" pretexts directing targets to OAuth phishing pages mimicking Microsoft login. Both vendors describe a new HYPERSCRAPE variant; Microsoft adds the detail that operators are using OAuth application consent grants requesting Mail.Read + Mail.ReadWrite scopes — a quieter persistence path that survives password resets. Targets are defense-policy think tanks, Iran-nuclear researchers, and MENA security journalists; no defense primes named as victims. Independent A-grade vendor corroboration with separate telemetry bases (Falcon vs. Defender/Entra) clears the corroboration test — digraph A1, WEP ceiling "very likely."

## Technical detail

- **Actor (per CrowdStrike + Microsoft):** Charming Kitten / Mint Sandstorm — IRGC-IO. Roster ID 011 (last reviewed 2026-04-08). Aliases per roster: APT35, Magic Hound, Mint Sandstorm, Phosphorus, Newscaster, Ajax Security Team, Yellow Garuda.
- **Campaign window:** February 2026 through April 2026.
- **Targets (per sources):** US, UK, Israeli defense-policy think tanks; Iran-nuclear-program researchers; journalists covering MENA security. CrowdStrike notified Brookings, RUSI, and Atlantic Council. **No defense primes named as victims.**
- **Initial access:** "Expert outreach" social-engineering pretext (fake conference invitations, fake research collaborations); pretexts invite targets to "comment on a paper draft" hosted on attacker-controlled OAuth phishing pages mimicking Microsoft login.
- **Tooling:** New HYPERSCRAPE credential exfiltration variant (originally documented by Mandiant 2022); updated PowerShell loader.
- **Persistence (Microsoft addition):** OAuth application consent grants — operators register attacker-controlled apps that request Mail.Read + Mail.ReadWrite scopes; targets click through consent dialogs. Application receives token; persistence survives password resets. Defenders should hunt via Entra audit logs (consent-to-application events).
