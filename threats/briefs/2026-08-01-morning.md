# Morning Brief — 2026-08-01

**Adobe and Ruby on Rails patched two critical unauthenticated RCE-class flaws — CVE-2026-48449 (CVSS 10.0) in Adobe Campaign Classic and CVE-2026-66066 (CVSS 9.5) in Rails Active Storage.** Neither is under active exploitation; both are fixed. Patch, then move on.

**Why it matters:** Both products can sit in A&D/DIB environments — Campaign Classic in marketing/comms, Rails under internal web tooling — and max-severity unauthenticated flaws are attractive post-disclosure targets, so the window to patch before a public PoC lands is now.

## 🔓 Vulnerabilities

**Adobe patched a max-severity Campaign Classic flaw — CVE-2026-48449, CVSS 10.0**
- What: An incorrect-authorization flaw permits unauthenticated, no-interaction arbitrary code execution in exposed Campaign Classic (ACC) environments; companion CVE-2026-48448 also affects ACC. Both fixed in ACC v7 7.4.3 build 9398 (Windows and Linux).
- Why it matters for A&D: Campaign Classic is enterprise marketing-automation that can run in DIB marketing/comms tenants; an internet-exposed, unpatched instance would be a max-severity unauthenticated entry point. Patched; no A&D victim named.
- Action: Inventory Campaign Classic deployments and apply build 9398 if not already on it.
- Source: [The Hacker News](https://thehackernews.com/2026/08/adobe-campaign-classic-cvss-100-flaw.html) (+ SecurityWeek, BleepingComputer, Tenable) · Digraph: B2 · WEP: likely
- Note: Adobe attests no known in-the-wild exploitation. Four B-grade relays trace to one Adobe APSB bulletin (single evidence basis) — WEP capped at "likely." CVE not yet in `_index.yaml`; vuln-tracker watch-tier add pending.

**Ruby on Rails patched a critical Active Storage file-read flaw — CVE-2026-66066, CVSS 9.5**
- What: An unauthenticated attacker can read arbitrary files, including the process environment, in Active Storage when apps display libvips-processed image variants and accept untrusted uploads; per Rapid7, a reachable `secret_key_base` enables lateral movement and remote code execution. Fixed in Active Storage 7.2.3.2 / 8.0.5.1 / 8.1.3.1.
- Why it matters for A&D: Rails underpins internal web tooling that DIB shops run; a file read that reaches `secret_key_base` turns into session forgery and potential RCE. Patched; no A&D victim named.
- Action: Patch Active Storage AND libvips (8.13+) — both layers — and prioritize apps that accept uploads and render image variants.
- Source: [SecurityWeek](https://www.securityweek.com/ruby-on-rails-patches-critical-vulnerability/) (relaying the Rails security release + Rapid7) · Digraph: B2 · WEP: likely
- Note: No active exploitation reported as of July 30. Single relay publisher in hand carrying two un-retrieved primaries (one evidence basis) — WEP capped at "likely." CVE not yet in `_index.yaml`; vuln-tracker watch-tier add pending.
