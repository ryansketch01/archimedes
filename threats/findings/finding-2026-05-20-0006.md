# Cisco Secure Workload CVE-2026-20223 CVSS 10.0 — unauthenticated REST API authentication bypass with cross-tenant Site Admin impact; patches available (no FLASH — 0 of 6 triggers fire despite maximum severity)

## Summary

Cisco PSIRT (advisory cisco-sa-csw-pnbsa-g8WEnuy, 2026-05-20 via NVD
publication) discloses a CVSS 10.0 unauthenticated REST API
authentication bypass in Cisco Secure Workload (formerly Cisco
Tetration) — CVE-2026-20223. CWE-306 (Missing Authentication for
Critical Function). An unauthenticated remote attacker can send
crafted REST API requests to obtain Site Admin privileges, enabling
read of sensitive information across tenant boundaries and
modification of configurations across tenant boundaries. The
cross-tenant scope-CHANGED dimension is what drives CVSS to the
10.0 ceiling.

**Affected:** On-prem 3.10 (fixed 3.10.8.3), on-prem 4.0 (fixed
4.0.3.17), on-prem 3.9 and earlier (no in-version fix; migration
required). **SaaS already mitigated per Cisco PSIRT — no action
required for SaaS customers.** No workarounds available.

**Exploitation status at disclosure:** Cisco PSIRT statement: "is not
aware of any public announcements or malicious use of the
vulnerability" at publication. Not in CISA KEV at grading time. No
public exploit code observed via passive search at 2026-05-20 15:33
EDT.

**No threat actor attribution.** Per Hard Rule 2, Archimedes does NOT
originate actor attribution. The Cisco-product-authentication-bypass
pattern across 2026 (this CVE + CVE-2026-20182 Catalyst SD-WAN +
CVE-2026-20093 IMC) is a verifiable corpus observation of three

**FLASH evaluation: 0 of 6 triggers fire despite CVSS 10.0.** Trigger

segmentation policies across program enclaves.

**CVE identifier and grading basis:**

**Vulnerability mechanism (high-level per Cisco PSIRT; no PoC reproduction per Hard Rule 3):**

Per NVD record + Cisco advisory, the issue stems from "insufficient validation and authentication when accessing REST API endpoints." An unauthenticated remote attacker can exploit this by sending crafted API requests to gain Site Admin privileges, with two operational impacts called out by Cisco PSIRT:

1. Read sensitive information across tenant boundaries
2. Modify configurations across tenant boundaries

The cross-tenant scope-CHANGED dimension is what drives CVSS to 10.0 — a single unauthenticated request from a network-reachable attacker can compromise the security boundary between tenants on a shared Secure Workload deployment.
