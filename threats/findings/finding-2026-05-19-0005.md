# CVE-2026-31635 DirtyDecrypt Linux kernel LPE-to-root via missing COW guard in rxgk_decrypt_skb — CVSS 7.5 — patched April 2026 — V12 PoC May 2026

## Summary

SecurityWeek relays the V12 security team's publication of a proof-of-concept exploit for CVE-2026-31635 ("DirtyDecrypt") — a Linux kernel LPE-to-root vulnerability in the RxGK subsystem (the security class for the RxRPC network protocol used by Andrew File System and OpenAFS). The bug is a missing copy-on-write guard in `rxgk_decrypt_skb` that accepts oversized response authenticators, resulting in data being written to the memory of privileged processes or to the page cache of privileged files such as SUID binaries. CVSS 7.5. The vulnerability was PATCHED in April 2026 mainline pre-disclosure; V12 published the PoC in May 2026 after patches landed. Affected distros are Arch Linux, Fedora, openSUSE with `CONFIG_RXGK` enabled — a niche AFS-stack deployment footprint. Container-platform worker nodes are the more A&D-relevant exposure if `CONFIG_RXGK` is enabled (rare on hardened production container images). No in-the-wild exploitation. No tracked actor. No named A&D-prime customer. Bug is a variant of the CopyFail + DirtyFrag + Fragnesia kernel-bug family — Archimedes has Fragnesia A1-anchored via finding-2026-05-14-0003.
