# vm2 npm sandbox escape multi-CVE cluster — CVE-2026-26956 (RCE-on-host) plus six related sandbox-escape CVEs; patches available, no active exploitation

## Summary

A coordinated cluster of seven sandbox-escape CVEs in the vm2 npm package was published 2026-05-06 to 2026-05-07. The headline case, CVE-2026-26956, is a critical sandbox escape via WebAssembly exception handling that yields remote code execution on the host running vm2; six companion CVEs (CVE-2026-44001 process-crash DoS plus five further sandbox escapes — CVE-2026-43997, -43999, -44005, -44006, -44007) were filed against vm2 in the same window. vm2 has 1.3 million weekly downloads on npm and is used by online coding platforms, automation tools, CI/CD preview environments, and SaaS user-script execution; A&D primes and Tier-1/2 supplier dev pipelines may transit vm2 directly or via embedded dependencies. The affected configuration is Node.js 25 with WebAssembly exception handling and JSTag support enabled. Patches are available (vm2 3.10.5+; latest 3.11.2). No active exploitation reported. CVSS scores are not yet in NVD for most of the cluster CVEs at grading time. BleepingComputer (B-grade) reports the cluster relaying the maintainer advisory; GitHub Security Advisories (B-grade) carries the structured GHSA records. The two publication surfaces are partially independent but both trace upstream to the vm2 maintainer disclosure pipeline. Cluster pattern (7+ CVEs simultaneously) is consistent with a coordinated maintainer audit response, plausibly AI-assisted vulnerability discovery in line with the Mandiant 2026-04-23 thesis on AI-accelerated vuln-finding. Recommend dependency-graph audit at A&D Tier-1/2 CI/CD surface; recommend `vuln-tracker` open a CVE-2026-26956 stub dossier with the six companion CVEs tracked as related.
