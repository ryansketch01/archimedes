## Technical detail

### Underlying vulnerability (carry-forward from finding-2026-05-14-0002)

CVE-2026-42945 is a heap buffer overflow in NGINX's `ngx_http_rewrite_module`. Trigger condition: servers using `rewrite` and `set` directives where escaped URI data overflows heap boundaries when question marks appear in rewrite replacements (per F5 K000160932 + depthfirst commentary via THN). A single crafted HTTP request can trigger the overflow without authentication.

### Severity caveat — ASLR dependency (carry-forward)

Code execution is "possible" primarily on systems with ASLR disabled. Standard hardened deployments with ASLR enabled (modern Linux distribution defaults) limit impact to denial-of-service via worker process crashes.

For A&D estate assessment, the ASLR configuration state is the determining factor:
- Modern Linux distribution defaults ship ASLR enabled — standard hardened web-tier deployments should be ASLR-on
- Legacy deployments on older / less-curated infrastructure may have ASLR disabled — vendor appliances with embedded NGINX, BIG-IP-embedded NGINX, internally-administered Kubernetes ingress controllers, IoT/OT-adjacent NGINX-on-embedded-Linux platforms
- F5 K000160932 likely includes specific configuration-state guidance; defer to vendor primary for authoritative posture recommendations

### Patched versions (carry-forward)

- NGINX Plus: R32 P6+, R36 P4+
- NGINX Open Source: 1.30.1, 1.31.0
- NGINX Ingress Controller: specific versions per F5 advisory
- NGINX App Protect WAF: specific versions per F5 advisory
