# Morning Brief — 2026-07-16

**CISA has ordered federal agencies to patch actively-exploited Oracle E-Business Suite flaw [CVE-2026-46817](../vulnerabilities/CVE-2026-46817/profile.md) by Saturday, July 18 — attackers are taking over the unauthenticated Oracle Payments module in the wild.**

**Why it matters:** Oracle EBS runs procurement, payments, and supplier financials across the defense industrial base; a pre-auth Payments takeover is a direct path to ERP-resident contract and payment data at ITAR-regulated primes.

---

## 🚨 Active Threats

**UPDATE: Oracle EBS CVE-2026-46817 is under active exploitation — federal patch deadline is Saturday, July 18**
- CISA added the unauthenticated Oracle Payments (File Transmission) takeover to KEV on July 15 with an accelerated BOD deadline; in-the-wild exploitation traces to roughly June 27.
- A&D impact: Oracle EBS is pervasive DIB ERP — a pre-auth takeover exposes payments and supplier data at ITAR-regulated primes.
- Action: Apply the Oracle May 2026 CPU (fixes EBS 12.2.3–12.2.15) now; with exploitation confirmed, unpatched internet-facing EBS is **likely** to be hit. Can't patch by Saturday? Restrict and monitor `/OA_HTML/ibytransmit`.
- Source: [CISA KEV catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) · Digraph: A2 (single-source veto; no actor attributed) · [VT-043 / CVE-2026-46817](../vulnerabilities/CVE-2026-46817/profile.md) · 🔗 previously "no exploitation, no KEV" (2026-06-01 morning brief).

**MSTIC discloses an @asyncapi npm supply-chain compromise — import-time "Miasma" loader, live C2**
- Microsoft disclosed the `@asyncapi` npm org was compromised July 14: five malicious versions across four packages run a loader at **import time** (so `--ignore-scripts` does not stop it), auto-published with valid OIDC provenance built from unauthorized commits.
- Assessment: **likely** opportunistic and ecosystem-wide — no victimology or sector targeting reported; a targeted-A&D read is **unlikely** but not ruled out. No actor named; a new deployment of the tracked Miasma family, not a first sighting.
- Action: Remove the five versions, purge npm/Yarn caches, hunt for `sync.js` in NodeJS-masquerade dirs, block outbound to **85.137.53.71** (8080/8081/8091), and rotate exposed credentials. A&D relevance is structural — `@asyncapi/specs` reaches CI/CD build graphs.
- Source: [Microsoft Threat Intelligence](https://www.microsoft.com/en-us/security/blog/2026/07/15/unpacking-asyncapi-npm-supply-chain-compromise-import-time-payload-delivery/) · Digraph: A2 (single-source veto; likely) · sibling to the tracked VT-006 / VT-009 npm lineage.

## 🔓 Vulnerabilities

**F5 patches unauthenticated NGINX heap overflow CVE-2026-42533 (CVSS 9.2) — DoS-primary, no exploitation**
- F5's quarterly notification K000161837 fixes an unauthenticated heap overflow in NGINX Plus and NGINX Open Source via a crafted-request regex `map` directive; it restarts the worker (DoS) and enables code execution **only where ASLR is disabled**.
- Scope: CVSS v4.0 9.2 Critical (NVD also carries CVSS v3.1 8.1 High; both AC:H). Fixed at disclosure — NGINX Open Source 1.31.3, NGINX Plus R37+. F5 reports no in-the-wild exploitation.
- Forward: **likely** to stay an n-day with DoS-primary risk; a KEV addition is **unlikely** near-term, but F5 edge flaws run rapid-to-KEV — KEV-watch is active. Patch now; RCE-exposure only on ASLR-disabled edge builds.
- Source: [SecurityWeek (F5 K000161837 relay)](https://www.securityweek.com/f5-patches-multiple-nginx-big-ip-vulnerabilities/) · Digraph: A2 · [VT-044 / CVE-2026-42533](../vulnerabilities/CVE-2026-42533/profile.md). Further NGINX Ingress / BIG-IP CVE IDs pending F5-primary retrieval.

**MONITORING: Nightmare Eclipse "LegacyHive" Windows profsvc LPE zero-day — no state change**
- SecurityWeek became a second outlet on the pseudonymous Nightmare Eclipse User Profile Service (`profsvc`) privilege-escalation zero-day — the 8th drop in the series; July 16 coverage is relay, not new evidence. Still no CVE, Microsoft silent, unpatched, no in-the-wild use. B2 / **likely**; no tracked actor (self-claimed persona; Hard Rule 2), severity disputed by researcher Matei Badanoiu.
- Source: [The Register](https://www.theregister.com/security/2026/07/15/microsofts-serial-tormentor-drops-legacyhive-0-day/5271723) · Digraph: B2 · [VT-042 / LegacyHive](../vulnerabilities/LegacyHive/profile.md).
