## Summary

CISA published an alert at 2026-05-20 08:00 EDT and updated the KEV
JSON feed the same morning, adding seven entries to the catalog "based
on evidence of active exploitation." Each carries the federal dueDate
2026-06-03 (BOD 22-01, 14-day window).

**Two fresh 2026 CVEs** target Microsoft Defender — the A&D-prime
universal EDR — and warrant immediate attention:

- **CVE-2026-41091** — Microsoft Defender link-following (CWE-59)

  EDR / AV coverage during follow-on intrusion activity.

update-guide page returned header-only via passive retrieval this

segments and lab environments running Windows Server 2003/2008,

  Conficker vector; 18-year-old bug still productive)
- CVE-2009-1537 — DirectX/quartz.dll NULL byte overwrite via crafted

- CVE-2009-3459 — Adobe Acrobat and Reader heap-based buffer overflow

## Technical detail

### Fresh 2026 Microsoft Defender CVEs (A&D-prime relevance: HIGH)

**CVE-2026-41091 — Microsoft Defender Link Following Vulnerability**

- Vendor / product: Microsoft Defender (the Microsoft Defender / Microsoft Defender Antivirus endpoint protection product family; same family as Microsoft Defender for Endpoint, Microsoft Defender Antivirus on Windows 10/11/Server)
- CWE: CWE-59 (Improper Link Resolution Before File Access)
- CISA KEV description: "Link following vulnerability permitting authorized attackers to elevate privileges locally"
- CVSS: not yet surfaced (NVD Awaiting Analysis; MSRC header-only)
- Attack mechanism class: link-following EoP against EDR product means a chained attacker with low-privilege foothold can pivot to higher privileges. Established attack class with multiple historical exemplars; the CVE-specific exploit chain is NOT reproduced here per Hard Rule 3.

**CVE-2026-45498 — Microsoft Defender Denial of Service Vulnerability**

- Vendor / product: Microsoft Defender
- CWE: none listed on KEV record
- CISA KEV description: "Unspecified vulnerability in Microsoft Defender enabling denial of service attacks"
- CVSS: not yet surfaced
- Attack mechanism class: DoS against the Defender service itself. On a Defender-only endpoint, this translates to suppression of EDR / AV coverage during follow-on intrusion activity (MITRE T1562.001 Disable Tools class).

**A&D-prime exposure:** Microsoft Defender (and Microsoft Defender for Endpoint) is deployed across the overwhelming majority of A&D-prime Windows endpoint fleets, often as the primary EDR layer or in dual-EDR-stack configurations. Both Defender CVEs are universal-deployment-impact across A&D primes following Microsoft endpoint protection.

### Historical CVEs resurfaced (A&D-prime relevance: STRUCTURAL-INDIRECT via EOL/lab/OT segments)

**CVE-2008-4250 — Microsoft Windows Buffer Overflow (MS08-067 RPC RCE)**

- The original Conficker worm vector. 18 years post-disclosure, still productive against unpatched / EOL Windows fleets (Server 2003 / 2008 / Windows XP / Windows 7 in production on isolated industrial / OT segments, or development / lab environments).
- CWE: CWE-94 (Code Injection)
- Bulletin: https://learn.microsoft.com/en-us/security-updates/securitybulletins/2008/ms08-067

**CVE-2009-1537 — DirectX NULL Byte Overwrite**

- quartz.dll DirectShow QuickTime Movie Parser Filter bug enabling RCE via crafted media files.
- Bulletin: MS09-028 quartz.dll

**CVE-2009-3459 — Adobe Acrobat / Reader Heap Buffer Overflow**

- RCE via crafted PDF files triggering memory corruption.
- CWE: CWE-119

**CVE-2010-0249 + CVE-2010-0806 — IE Use-After-Free pair**

- CVE-2010-0249: the IE 0-day used in Aurora attacks against Google + 30+ other companies in 2009-2010 (historically attributed to Chinese state actors per McAfee + Google 2010 reporting). CISA's 2026 KEV addition is for **current** ITW against modern unpatched / EOL fleets — NOT a re-attribution to Aurora-era actors.
- CVE-2010-0806: companion use-after-free.
- CWE: CWE-416 (CVE-2010-0249), CWE-399 (CVE-2010-0806)

**A&D-prime exposure:** A&D OT segments, lab/dev environments, and CMMC L2-L3 enclaves operating legacy Windows endpoints are the typical attack surface for these historical CVEs. ITAR-regulated manufacturing environments occasionally run legacy Windows Server in tightly firewalled / air-gapped configurations precisely BECAUSE patching breaks vendor-controlled industrial software — these are exactly the unmanaged fleets CISA's KEV addition targets.
