# ⚡ FLASH: No patch exists for a critical, actively-exploited RCE in the end-of-life Fastjson 1.x Java library — mitigate now

*2026-07-28 06:25 EDT · B2 · WEP: likely · TLP:CLEAR · Queued (quiet hours — 09:00 catch-up; likely absorbed into the 08:00 morning brief)*

**What.** SecurityWeek reports active in-the-wild exploitation of **[CVE-2026-16723](../vulnerabilities/CVE-2026-16723/profile.md)** — an unauthenticated, no-interaction RCE (CVSS 9.0, claimed) in the **Fastjson 1.x** Java JSON library (versions 1.2.68-1.2.83), triggered by a crafted `@type` payload that manipulates type-resolution logic. Fastjson 1.x is end-of-life, so **there is no official patch.**

**Impact.** Fastjson is a Log4j-class ubiquitous Java library — DIB exposure is plausibly high wherever Java stacks parse untrusted JSON, and an unauthenticated no-patch RCE is a worse posture than a patchable n-day. No aerospace or defense victim is named; reported targeting is broad commercial (financial services, healthcare, retail, computing, business) across the US, Singapore, and Canada. A&D relevance is structural, not observed.

**Confidence — read the caveat.** B2 / likely. Both the CVE facts and the exploitation claim reach us through a single retrievable relay — SecurityWeek (provisional B) — carrying three un-retrieved originators (Alibaba's advisory, ThreatBook and Imperva telemetry). Independent corroboration is not established, so the single-source veto caps this at "likely." Not CISA-KEV-listed as of the 06:00 sweep. No threat actor named.

**Action.** *No patch exists — mitigate today.* Inventory Fastjson 1.x (1.2.68-1.2.83) across your Java estate, including copies embedded in Spring Boot fat-JARs. Enable SafeMode (`-Dfastjson.parser.safeMode=true`), adopt the restricted `1.2.83_noneautotype` build, or migrate to Fastjson2 (not affected). Prioritize internet-reachable services that parse untrusted JSON.

**Sources.** [SecurityWeek](https://www.securityweek.com/unpatched-fastjson-vulnerability-exploited-in-attacks/) (B — sole retrievable relay; carries the Alibaba advisory plus ThreatBook and Imperva telemetry, none directly retrieved).

**Related.** [CVE-2026-16723](../vulnerabilities/CVE-2026-16723/profile.md) — no patch (1.x EOL), mitigation-only; net-new to brief coverage. No actor (Hard Rule 2).
