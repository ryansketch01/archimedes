# FLASH UPDATE: Oracle PeopleSoft zero-day now CVE-2026-35273; Mandiant CTO attests in-the-wild exploitation; Oracle ships out-of-band mitigations advisory with no GA patch

*2026-06-11 12:00 EDT · A2 · WEP: likely (operational ITW) / very likely (procedural CVE-facts) · TLP:GREEN*

**UPDATE on [yesterday's 16:00 brief](./2026-06-10-afternoon.md) (finding-2026-06-10-0012).** Four material changes since yesterday's PM coverage: the vulnerability is now **CVE-2026-35273**; Oracle issued an out-of-band advisory providing **mitigations** with no GA patch; Mandiant CTO Charles Carmakal publicly attested in-the-wild exploitation via LinkedIn; and the University of Nottingham issued a public statement confirming victim status (was leak-site-mentioned only yesterday). Trigger 6 (zero-day without patch) conditions now formally exist.

**What:** Critical-severity unauthenticated pre-auth RCE in Oracle PeopleSoft (PeopleTools 8.61 / 8.62; earlier unsupported versions possibly affected). Oracle's advisory characterizes it as *"remotely exploitable without authentication, may result in remote code execution"* and calls mitigation *"high-priority risk reduction measure"*. **NVD has not published a CVSS score — do not assert a number.** Independent researcher @nahamike01 corroborates at the tradecraft layer (B3 supplementary). Mandiant's ITW attestation and ShinyHunters' self-claimed 100+-org scale are independent evidence bases — one does NOT confirm the other.

**Impact for A&D:** Structural-indirect only — PeopleSoft is enterprise HR/ERP backbone class; primes on PeopleTools 8.61 / 8.62 are mechanically in the affected population. **No A&D-prime victim is named** at any in-window source; relevance is structurally plausible, empirically unmeasured (LiteSpeed / cPanel precedent). Per Hard Rule 2: ShinyHunters is NOT in `_roster.yaml`; reported strictly as self-claim relayed by BC / SW / The Record. Their multi-year victimology (consumer / retail mass-data-theft) is off-profile for A&D primes — don't read 100+ scope as A&D forecast.

**Action.**
- **Inventory exposed PeopleSoft instances now** — internet-facing first; check PeopleTools version against 8.61 / 8.62 (treat earlier unsupported versions as in scope).
- **Apply Oracle's out-of-band mitigations immediately.** Support-account customers pull the full patch via advisory; everyone else mitigates while GA patch is pending.
- **Hunt against the 7 IOCs already in corpus** (IPv4 142.11.200.186-190, 108.174.202.99, 176.120.22.24; domain azurenetfiles.net) — see [finding-2026-06-10-0012](../findings/finding-2026-06-10-0012-bleepingcomputer-oracle-peoplesoft-shinyhunters-self-attested-300-instances-100-orgs-gadget-chain-failed-fbi-attempt-7-iocs.md). No new IOCs this hour.
- **Watch for second IR-firm corroboration** (Unit 42, CrowdStrike, MSTIC, Volexity, Sophos) or CISA KEV addition — either lifts operational ITW WEP from *likely* to *very likely*.
