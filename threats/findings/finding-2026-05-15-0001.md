# TeamPCP advertises Mistral AI 450-repo / 5GB exfil for $25K BIN — second named-enterprise victim on Mini Shai-Hulud / TanStack mechanism (B2, likely)

## Summary

TeamPCP (tracked actor #001, HIGH) advertised approximately 450 Mistral AI internal repositories totaling roughly 5GB for sale at $25,000 BIN on a cybercriminal forum on 2026-05-14, threatening public leak if no buyer materializes within one week. Mistral AI confirms its codebase management system was compromised on 2026-05-12 via the same third-party software supply chain attack that affected TanStack — the Mini Shai-Hulud / CVE-2026-45321 mechanism Wiz, Snyk, and StepSecurity attributed to TeamPCP on 2026-05-12. Mistral's statement minimizes scope to non-core code repositories and rules out hosted services, managed user data, and research/testing environment compromise. The ~450-repo / ~5GB scope claim is TeamPCP's own forum-post self-claim; no independent vendor research has verified it within the 24h window.

This is the second named-enterprise victim confirmation on the Mini Shai-Hulud / TanStack mechanism after OpenAI (finding-2026-05-14-0008). The data-monetization stage is a downstream cybercriminal pattern consistent with TeamPCP's roster classification (Cybercriminal, nation unknown).
