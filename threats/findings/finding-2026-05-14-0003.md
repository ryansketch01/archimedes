# Linux Kernel LPE Cluster — CVE-2026-46300 "Fragnesia" PoC + CVE-2026-31431 "Copy Fail" KEV Deadline TOMORROW

## Summary

Two Linux kernel privilege-escalation CVEs converge on the 2026-05-14 morning brief defensive-posture window. **CVE-2026-46300 "Fragnesia"** is a XFRM ESP-in-TCP subsystem logic bug enabling arbitrary byte writes into the kernel page cache; it affects all Linux kernels released before 2026-05-13. Researcher William Bowling (Zellic) has released a working proof-of-concept that corrupts the page cache of `/usr/bin/su` to obtain a root shell. Kernel patch shipped on the netdev mailing list 2026-05-13; Linux distributions are rolling updates. Mitigation via `rmmod esp4 esp6 rxrpc` is available but breaks IPsec VPNs and AFS distributed file systems. No in-the-wild exploitation reported at disclosure.

**CVE-2026-31431 "Copy Fail"** is a second Linux kernel LPE — actively exploited per CISA KEV (dateAdded 2026-05-01) with federal-agency BOD-22-01 remediation deadline **2026-05-15 (TOMORROW)**. This is the first Archimedes-corpus surfacing of Copy Fail as actively exploited (cross-referenced via BleepingComputer's Fragnesia piece).

The two CVEs form a 13-day Linux-kernel-LPE-cluster narrative: Copy Fail is the "exploited TODAY" anchor with imminent federal deadline; Fragnesia is the "weaponizable TOMORROW" anchor with PoC published and rapid-weaponization risk. The morning brief defensive-posture-action section should treat them as a combined cluster, not parallel items.

Combined with finding-2026-05-14-0002 (NGINX Rift CVE-2026-42945), this morning's defensive-posture-action surface is unusually load-bearing: three high-deployment-surface CVE disclosures converging in a single 24h window.

## Technical detail

### Fragnesia (CVE-2026-46300)

**Vulnerability mechanism:** Logic bug in the Linux XFRM ESP-in-TCP subsystem enabling arbitrary byte writes into the kernel page cache of read-only files. No race conditions required.

**PoC:** Researcher William Bowling at Zellic released a working proof-of-concept that corrupts the page cache of `/usr/bin/su` to obtain root-level shell access. Public exploit available.

**Affected kernels:** All Linux kernel versions released before 2026-05-13. The deployment surface is total: every Linux server, every workstation, every virtual appliance, every Kubernetes worker node, every Docker host, every embedded-Linux device manufactured before mid-May 2026.

**Vulnerability class:** Belongs to the "Dirty Frag" class. Distinct from prior Dirty Frag CVEs (CVE-2026-43284 and CVE-2026-43500) which chained multiple kernel flaws.

**Patches:** Linux kernel netdev mailing list patch 2026-05-13. Distros rolling.

**Mitigation:** `rmmod esp4 esp6 rxrpc` disables the vulnerable modules. **This breaks IPsec VPNs and AFS distributed file systems.** Operationally material for any A&D environment using IPsec for site-to-site VPNs to subcontractors / cleared-remote endpoints, or AFS for legacy distributed-storage in classified-development environments. Patch-first guidance preferred; mitigation reserved for systems where patch cannot be applied within the threat-actor-weaponization window.

**Exploitation status:** No in-the-wild exploitation reported at publication. PoC publicly released — rapid-weaponization risk is the forward concern.

**CVSS:** Not stated in BleepingComputer or The Hacker News. NVD entry not yet indexed at sweep time. "High-severity" framing per BC is qualitative.
