## 🔓 Vulnerabilities

**CIFSwitch — Linux kernel `cifs.spnego` LPE; PoC released post-patch; no CVE assigned; no ITW** *([finding-2026-06-01-0001](finding-2026-06-01-0001-securityweek-bleepingcomputer-cifswitch-linux-kernel-cifs-spnego-lpe-poc-released-multi-distro-no-cve-assigned-no-itw-per-a-grade-spacex-researcher.md))*

- **What.** [SecurityWeek](https://www.securityweek.com/19-year-old-linux-kernel-vulnerability-exposes-systems-to-root-access/) (Ionut Arghire, 07:19 EDT) reports a proof-of-concept released for a local-privilege-escalation flaw in the Linux kernel `cifs.spnego` key upcall, dubbed **CIFSwitch**. [BleepingComputer](https://www.bleepingcomputer.com/news/security/) (Bill Toulas, May 30) names the researcher as Asim Manizada, a SpaceX security engineer. Originating disclosure is the [oss-security mailing list](https://www.openwall.com/lists/oss-security/2026/05/28/2) post May 28.
- **Mechanism (analytic class only per Hard Rule 3).** Improper validation in the `cifs.spnego` key upcall handler lets an unprivileged local user impersonate trusted kernel requests and escalate to root. **Local attack vector — requires pre-existing unprivileged shell.**
- **No CVE assigned, not on KEV, no Tier-1 IR firm has corroborated technical substance.** Mandiant, Volexity, Unit 42, MSTIC, CrowdStrike all silent.
- **Affected distros (`cifs-utils` default-installed):** Linux Mint, CentOS, Rocky, Kali, AlmaLinux, SLES SAP per B-grade trade-press. Default-blocked on most Ubuntu / Fedora. Patches landed across major distros earlier in May; upstream kernel commit `3da1fdf4efbc490041eb4f836bf596201203f8f2` validates `cifs.spnego` request origins.
- **A&D action.** Inventory `cifs-utils` default-installed hosts (`dpkg -l` / `rpm -q`); verify patches against the upstream commit or distro advisory equivalents. SLES SAP estates (highest structural DIB concentration) verify against the SUSE SAP-base channel.
- It is **likely** an A-grade IR firm publishes technical validation or ITW observation within 30 days as disclosure spreads; resurface trigger.
- Digraph B2 · WEP ceiling **likely** under single-source veto on the technical-substance layer (both B-grade relays derive from the same researcher primary) · finding-2026-06-01-0001.

**Carry-forward — Oracle CPU May 2026 critical batch** *([finding-2026-05-29-0003](2026-05-29-morning.md))*: CVE-2026-46840 (REST Data Services, 10.0), CVE-2026-46817 (EBS Payments, 9.8), CVE-2026-46833 (Database Net Service, 9.0). No ITW or KEV at T+4; public-PoC watch through 2026-06-11.
