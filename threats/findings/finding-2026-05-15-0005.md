# node-ipc npm Compromise — Four-Firm Research Consensus on UNATTRIBUTED Status (Socket + StepSecurity + Ox Security + Upwind)

## Summary

BleepingComputer (Bill Toulas) published a fuller technical writeup on the node-ipc npm package compromise that surfaced 2026-05-14 (finding-2026-05-14-0009). The article cites four research firms — Socket, StepSecurity, Ox Security, and Upwind — all declining to attribute the activity to TeamPCP, Shai-Hulud, Mini Shai-Hulud, or any tracked threat actor. This converts yesterday's corroboration ambiguity (Socket + StepSecurity co-primary independence held conservatively at B2) into a four-firm research consensus on UNATTRIBUTED status.

The underlying compromise facts are unchanged: three malicious node-ipc versions (9.1.6, 9.2.3, 12.0.1) published via the inactive 'atiertant' maintainer account; ~690,000 weekly downloads at compromise; ~90 credential categories targeted; dual-channel exfil via HTTPS-POST and DNS-TXT to bootstrap resolver `sh[.]azurestaticprovider[.]net`. The IOC set is identical to yesterday's grading.

New operational-discipline detail surfaces in this writeup: an exfil-overhead metric of approximately 29,400 DNS queries per 500 KB compressed archive; a 4 MiB file-size ceiling above which the stealer skips files; path exclusions for `.git` and `node_modules` directories; no persistence mechanisms; cleanup of temporary tar.gz archives post-exfiltration. Bill Toulas frames these characteristics as "operational discipline" signals consistent with single-pass smash-and-grab credential exfil — a different operational profile from Mini Shai-Hulud's worm-propagation model in finding-2026-05-12-FLASH-0001.

For an A&D-prime estate, the operational disposition is unchanged from yesterday: rotate any AWS / GitHub / Terraform / cloud / SSH credentials potentially exposed via node-ipc consumption in DIB / DFARS-supply-chain CI/CD estates. The cross-corroboration strengthens the cluster-separation analysis from finding-2026-05-14-0009 (H1 = separate cluster, not TeamPCP family expansion).
