# PCPJack worm — cloud-native credential-stealer that displaces TeamPCP infections; SentinelOne hypothesizes "former TeamPCP operator"

## Summary

SentinelOne / SentinelLabs published research on a worm framework
named "PCPJack" that targets cloud-exposed dev/build infrastructure
(AWS, Docker, Kubernetes, Redis, RayML, MongoDB) for credential theft
and deterministically removes TeamPCP (roster id 001) tools and
artifacts before deploying its own payload. PCPJack exploits five
CVEs in widely-deployed open-source components (Next.js, React2Shell,
WPVivid, W3 Total Cache, CentOS Web Panel) for initial access.
SentinelOne hypothesizes — with hedged language — that the operator
"could be a former operator who is deeply familiar with the group's
tooling," citing similarities to early TeamPCP/PCPCat campaigns from
December 2025. BleepingComputer (2026-05-07) and SecurityWeek
(2026-05-08) relay the SentinelLabs research without independent
corroboration. Per Hard Rule 2 the attribution hypothesis is recorded
verbatim and NOT promoted as attribution.

## Technical detail

PCPJack kill-chain per SentinelOne (relayed):

1. **Initial access** — exploits one of five CVEs:
   - CVE-2025-29927 (Next.js)
   - CVE-2025-55182 (React2Shell)
   - CVE-2026-1357 (WPVivid WordPress backup plugin)
   - CVE-2025-9501 (W3 Total Cache WordPress)
   - CVE-2025-48703 (CentOS Web Panel)

2. **Foothold** — Linux shell script for environment setup; payload
   fetch from AWS S3 (six modules); Python virtual environment
   creation.

3. **Displacement** — explicit scan for TeamPCP tooling and removal
   of artifacts, "claiming the compromise for themselves" per quoted
   research.

4. **Persistence + execution** — orchestrator launch, persistence
   establishment.

5. **Credential theft** — SSH keys, .env files, AWS creds, Kubernetes
   tokens, Docker creds, GitHub, Gmail, Office 365, Slack,
   WordPress; per BleepingComputer relay also Slack tokens, OpenAI/
   Anthropic API keys, Discord, DigitalOcean credentials.

6. **Lateral movement / propagation** — system reconnaissance,
   self-propagation against further cloud workloads.

The inter-actor displacement behavior (active rival cleanup before
deployment) is unusual but not unique in cybercriminal cloud
ecosystems. The hedged attribution hypothesis ("could be a former
TeamPCP operator") rests on (a) deep familiarity with TeamPCP
tooling implied by the cleanup logic and (b) campaign similarities
to early TeamPCP / PCPCat work from December 2025. Neither
constitutes attribution; both are pattern-matching within
SentinelOne's own analytic frame.

PCPJack-specific IOCs (S3 payload URLs, sample hashes, C2 endpoints)
were not surfaced in the SecurityWeek or BleepingComputer extracts.
The SentinelOne primary report URL was not surfaced in either relay
fetch — flag for follow-up.
