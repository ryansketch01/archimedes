# Linux kernel "Copy Fail" LPE (CVE-2026-31431) is being exploited in the wild against major distributions, federal patch deadline 2026-05-15

## Summary

CISA added CVE-2026-31431 to the Known Exploited Vulnerabilities catalog on 2026-05-01, and Microsoft MSTIC published independent confirmation the same day that the flaw — a logic error in the Linux kernel's `algif_aead` AF_ALG cryptographic API module — enables unprivileged-to-root local privilege escalation across cloud Linux workloads. Affected kernels span builds from 2017 through the patch date, hitting Ubuntu 24.04 LTS, Amazon Linux 2023, RHEL 10.1, SUSE 16, and Kubernetes nodes broadly. Theori released a public "100% reliable" exploit on 2026-05-01 (per BleepingComputer, citing the researchers); distros began pushing kernel updates after disclosure. Federal agencies have until 2026-05-15 under BOD 22-01.
