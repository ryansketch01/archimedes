## 📰 Other Signal

**Megalodon — mass GitHub-repo backdooring via `workflow_dispatch` anti-recursion bypass (monitoring; novel attack class in corpus)**
- What: SafeDep disclosed a CI/CD supply-chain campaign in which forged-identity commits (`build-bot`, `auto-ci`, `ci-bot`, `pipeline-bot` from 8-character throwaway accounts like `rkb8el9r`) added GitHub Actions workflow files across many repositories during a tight 6h17m window on 2026-05-18. The abuse mechanism exploits GitHub's intended-by-design `workflow_dispatch` anti-recursion behavior — a workflow file that adds another workflow file does not retrigger itself, so CI-time payloads deploy without firing recursive-trigger detection. SafeDep names three load-bearing victims: **Tiledesk** (downstream npm `@tiledesk/tiledesk-server@2.18.6` through `2.18.12` poisoned via the legitimate maintainer `eljohnny`; clean version 2.18.5), **Black-Iron-Project** (8 repos), and **WISE-Community**. SafeDep also reports a long-tail of roughly 5,500 smaller repositories; that scope layer rests on SafeDep's internal tooling alone and is the weakest evidentiary tier. Payloads execute base64-decoded bash one-liners targeting CI environment variables, cloud credentials, SSH keys, and CI/CD tokens. C2: `216.126.225.129:8443`.
- Why it matters for A&D: Structural-indirect only — no A&D prime named as victim, no Tiledesk A&D deployment context surfaced. The actionable defender takeaway is GitHub Actions workflow-file integrity at the org level: alert on `.github/workflows/*.yml` additions from accounts without prior commit history, and audit any pinned `@tiledesk/tiledesk-server` versions in DIB engineering estates.
- Source: [SecurityWeek](https://www.securityweek.com/over-5500-github-repositories-infected-in-megalodon-supply-chain-attack/) relaying [SafeDep](https://safedep.io/megalodon-mass-github-repo-backdooring-ci-workflows) primary · Digraph: C2 · WEP: likely (single-source veto applies — SafeDep sole originating; SecurityWeek pure relay)
- Hard Rule 2: **SafeDep explicitly declines attribution. Author-identity spoofing (`build-bot` / `auto-ci` / `ci-bot` / `pipeline-bot` here; `claude@users.noreply.github.com` in the May TeamPCP Mini Shai-Hulud cluster; `atiertant` in node-ipc) is a portable technique-class shared across multiple unattributed operators in the current SDLC-targeting wave. Archimedes does not collapse Megalodon, TrapDoor, TeamPCP, and node-ipc into a single actor.** Tiledesk downstream framing: SafeDep reports the causal chain; maintainer `eljohnny` has not publicly confirmed.
- Analyst caveats: Three load-bearing assumptions qualified — (1) SafeDep-faithful-relay (no second A/B-grade vendor independently audited the 5,561 figure or the two payload-variant taxonomy); (2) `workflow_dispatch` anti-recursion abuse is genuine vs. legitimate-but-unusual CI/CD automation (Tiledesk + Black-Iron + WISE samples evidence-grade, 5,500 long-tail not individually triaged); (3) Tiledesk causal link (verifiable in principle via npm tarball diff, not yet confirmed by Socket or eljohnny). Related: finding-2026-05-25-0001.
