Microsoft MSTIC published a Kazuar-malware architectural deep-dive on 2026-05-14T11:00 EDT documenting the evolution of Kazuar from "a relatively traditional backdoor into a highly modular peer-to-peer (P2P) botnet ecosystem." MSTIC attributes the malware family to **Secret Blizzard** (aliases VENOMOUS BEAR, Uroburos, Snake, Blue Python, Turla, WRAITH, ATG26) and explicitly cites CISA's prior attribution of Secret Blizzard to **Center 16 of Russia's Federal Security Service (FSB)**.

## Technical detail

**Three-module Kazuar architecture (per MSTIC):**

1. **Kernel module** — central coordinator. Issues tasks to Workers, manages Bridge communication, maintains action/data logs. Performs extensive anti-analysis and sandbox checks (process-scan, canary-file-check, loaded-DLL-check). Configuration set spans 150 different configuration types now embedded in samples (previously file-based).

2. **Bridge module** — sole external-C2-facing component. Three external transports: Exchange Web Services (EWS), HTTP, and WebSockets (WSS) — with redundant or fallback communications. Restricting external comms to a single elected leader is core to the architecture's evasion strategy.

3. **Worker module** — task executor. Communicates with Kernel via internal IPC, not directly with external C2.

**Leader election protocol:** A single Kernel leader per botnet is elected based on "amount of work divided by interrupts (reboots, logoffs, process terminated)." This load-balancing-aware coordinator selection reduces botnet observable footprint and enables flexible tasking.

**Delivery chain (two methods observed by MSTIC):**

1. **Pelmeni dropper** — embeds the encrypted second-stage Kazuar payload as an encrypted byte array. Payload is often bound to target environment (e.g., encrypted using target hostname) so it only decrypts on intended hosts. This anti-analysis technique is consistent with long-running APT tradecraft.

2. **Dropper + .NET loader** — small .NET loader deployed alongside final payload. Loader is often configured as a COM object, invoked with decrypted payload, allowing in-memory execution.

**Victim sectors (verbatim per MSTIC):** ministries of foreign affairs; embassies; government offices; defense departments; defense-related companies worldwide.

**Geographic targeting:** Europe; Central Asia; Ukraine (overlap with Aqua Blizzard victims).
