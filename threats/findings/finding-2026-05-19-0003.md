# CVE-2026-8153 Universal Robots PolyScope 5 cobot Dashboard Server unauth OS command injection — CVSS 9.8 — patched in 5.25.1 — STRONG A&D-supplier-tier structural relevance

## Summary

SecurityWeek reports CVE-2026-8153 — an unauthenticated OS command injection vulnerability in the Dashboard Server interface of Universal Robots PolyScope 5 cobot control software, CVSS 9.8 CRITICAL. The vulnerability allows a remote unauthenticated attacker with network access to the Dashboard Server port to execute commands on the robot's operating system. Claroty Team82 (researcher Vera Mens) originated the research; CISA cross-listed the finding in joint advisory ICSA-26-134-17 with Universal Robots. The vendor patched the issue in PolyScope 5.25.1. Vera Mens warns that cobot Ethernet control ports are often deployed on flat networks lacking proper segmentation, so initial-foothold acquisition may not be difficult (paraphrased per Rule 6 from a 12-word researcher quote at ceiling). Impact ranges from complete control of a single cobot (which Vera Mens notes may pose hazards to humans) to compromise of an entire fleet of cobots and their peripherals. No in-the-wild exploitation is documented; no tracked actor named; no victim named. Structural A&D-supplier-tier relevance is HIGH: Universal Robots cobots are deployed in aerospace manufacturing supplier-tier per public industry references (Airbus, Boeing, Lockheed Martin Tier-1/2 supplier inventories for assembly/inspection lines). This is among the strongest A&D-supplier-tier-relevant industrial vulnerabilities of 2026-Q2 to date in the Archimedes corpus.
