# Morning Brief — 2026-05-30

**Microsoft MSTIC discloses an active npm dependency-confusion cluster — 33 malicious packages, three yandex.ru maintainer aliases, a shared `X-Secret` HTTP header gate on a single C2, no APT attribution, no A&D targeting.** npm and MSTIC coordinated removal of all packages before publication; the defensive value is a universal HTTP-header signal that flags the campaign regardless of destination.

**Why it matters:** This cluster is not targeting the DIB — impersonated scopes are Russian-speaking fintech and e-commerce. But the mechanism (dependency confusion, postinstall stager, server-side payload gate) is universal to any developer environment, so the detection artifacts apply to your prime's CI/CD regardless.

## 🚨 Active Threats

**MSTIC: 33-package npm dependency-confusion cluster, `oob.moika.tech` C2, operator-only attribution**

- [Microsoft MSTIC](https://www.microsoft.com/en-us/security/blog/2026/05/29/33-malicious-npm-packages-abuse-dependency-confusion-profile-developer-environments/) published Friday May 29: 33 malicious packages under nine spoofed organizational scopes, by three new maintainer accounts (`mr.4nd3r50n`, `ce-rwb`, `t-in-one` — all yandex.ru). Two publication bursts: May 28 18:47–19:03 UTC and May 29 09:01–09:02 UTC. MSTIC assesses **"three accounts operated by the same individual"** (7 words) with high confidence on forensic npm registry metadata, and explicitly declines APT / nation-state attribution — operator-level only. Per Hard Rule 2, Archimedes does not extend the attribution; the three aliases are not in the roster.
- **Mechanism.** Packages ship inflated version numbers (`100.100.100`, `99.5.7`) to win the dependency-confusion race against private-registry packages. Each `scripts/postinstall.js` is a ~7KB Obfuscator.io-style stager that posts to `oob.moika.tech/payload/{win,mac,linux}` with hardcoded `X-Secret: l95HdDaz3kQx1Zsg3WxH6HvKANf51RY1`. C2 returns the platform-specific payload only when the header is present.
- **Payload state — factual, not intent.** MSTIC observes the deployed payload runs in reconnaissance-only mode (environment fingerprinting plus credential recon via process environment) with a server-side toggle for follow-on. Whether this reflects deliberate operator patience or mid-development tooling shipped early is not determinable in window. Report as observed state, not strategic intent.
- **Operator lifecycle observation.** `mr.4nd3r50n`'s npm history: v0.0.0 "Bugbounty"-tagged packages in April 2024, ~2-year dormancy, then 2026-05-28 malicious bursts. Analyst ACH (likely) ranks deliberate account-aging-as-cover as most parsimonious; a genuine bug-bounty pivot cannot be ruled out. Defensible observation, not predictive of attribution.
- **No A&D nexus.** Impersonated scopes: Sberbank SberPay (`@sber-ecom-core`), a Wildberries-shaped e-commerce scope (`@wb-track`), `@capibar.chat`, generic dev-infra shapes. Zero defense-contractor / DIB / ITAR / aerospace references in MSTIC's reporting. Detections still apply — mechanism is universal.
- **A&D action — apply now.** Push the four detections below into CI/CD edge and developer-laptop EDR today.
  - DNS / proxy block: `oob.moika.tech` and `*.cloudplatform-single-spa.io` (`github.`, `docs.`, `jira.` subdomains).
  - HTTP-header detection: alert on any request carrying `X-Secret: l95HdDaz3kQx1Zsg3WxH6HvKANf51RY1`.
  - npm policy: scope / maintainer allowlisting on internal registries; alert on any public package version numerically higher than a private-registry version.
  - Postinstall hook restriction: `npm install --ignore-scripts` at org-policy level blocks the stager outright.
- Splunk first-party silent on the 11-token IOC set over -14h (60-day `defenseclaw_local` dormancy; not disconfirming per Hard Rule 8).
- Digraph A2 (cluster anchor) · WEP **likely** (single-source veto on attribution + campaign envelope) · finding-2026-05-30-0001 · 23 IOCs enumerated in raw-signal; IOC index update queued.

**Cross-cluster geometry — methodologically distinct, not a lineage claim.** MSTIC published two npm supply-chain findings 22 hours apart ([vpmdhaj typosquat 2026-05-28](2026-05-29-morning.md), this cluster 2026-05-29) and did not link them. Divergences in MSTIC's own evidence: C2 architecture (X-Secret-gated single-stage vs. two-generation Bun-runtime), payload posture (recon-only-with-toggle vs. active full credential stealer), Defender family-signature (no `Trojan:JS/ShaiWorm`), primitive (dependency confusion vs. typosquat), maintainer profile (yandex.ru / Russian-speaking vs. gmail / DevOps-config). Analyst ACH affirms methodological distinctness on MSTIC's reported evidence. Per Hard Rule 2, Archimedes does not originate a lineage claim.
