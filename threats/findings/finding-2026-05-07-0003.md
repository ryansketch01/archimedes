# Sophos (via BleepingComputer): counterfeit claude-pro[.]com site delivers new Beagle Windows backdoor; DLL-sideloading chain via signed G Data updater; Sophos hedges PlugX-operator overlap

## Summary

Sophos research, relayed by BleepingComputer (Bill Toulas, 2026-05-07 06:02 EDT), reports a counterfeit Anthropic / Claude AI distribution site (claude-pro[.]com, defanged) delivering a previously undocumented Windows backdoor named Beagle. Targeting is software developers via AI-brand impersonation: the operator's lure markets a "high-performance relay service designed specifically for Claude-Code developers." Distribution chain: 505MB malicious archive (Claude-Pro-windows-x64.zip) drops a signed G Data updater binary (NOVupdate.exe) used for DLL-sideloading of avk.dll, which loads the encrypted DonutLoader payload that ultimately launches the Beagle backdoor. C2 infrastructure: license[.]claude-pro[.]com (defanged) over TCP/443 + UDP/8080, AES-encrypted, hosted on Alibaba Cloud range (8.217.190.58). Beagle command set: uninstall, cmd, upload, download, mkdir, rename, ls, rm — consistent with a foothold-establishment backdoor. Sophos hedges attribution with "the same operators behind PlugX might be experimenting with a new payload"; PlugX is historically associated with multiple China-nexus tracked actors but Archimedes does NOT originate the cross-walk per Hard Rule 2. Single-source single-vendor (Sophos via BleepingComputer); single-source veto applied; WEP capped at "likely." First-party Splunk clean for the IOCs at finding creation time. Librarian to add IOCs to master-index and re-query post-ingestion; if a hit surfaces, generate fresh FLASH per Trigger-3 and re-grade.

## Technical detail

- **Lure / initial access:** Counterfeit AI-brand site (claude-pro[.]com) impersonating Anthropic / Claude branding. Lure copy markets "high-performance relay service designed specifically for Claude-Code developers" — explicit developer targeting.
- **Distribution chain:**
  1. Fake site claude-pro[.]com offers Claude-Pro-windows-x64.zip (505MB).
  2. ZIP contains an MSI installer.
  3. MSI drops signed G Data updater binary NOVupdate.exe (used for DLL-sideloading).
  4. NOVupdate.exe sideloads avk.dll (malicious DLL).
  5. avk.dll loads NOVupdate.exe.dat (encrypted payload) — DonutLoader first stage.
  6. DonutLoader executes Beagle backdoor.
- **Beagle command set:** uninstall, cmd, upload, download, mkdir, rename, ls, rm. Consistent with a foothold-establishment backdoor; does NOT include native lateral-movement, credential-dumping, or persistence mechanisms in the published command catalog (these may be implemented as future-stage modules not yet observed).
- **C2 infrastructure:** license[.]claude-pro[.]com (subdomain of fake distribution site). 8.217.190.58 (Alibaba Cloud range, per Sophos via BleepingComputer). Protocol mix: TCP/443 + UDP/8080. Encryption: AES.
- **Attribution language (Sophos quote, under 15-word ceiling):** "The same operators behind PlugX might be experimenting with a new payload." This is hedged speculation, NOT assertion. Archimedes does not originate cross-walk to any roster actor on the basis of this hedge per Hard Rule 2.

## A&D relevance — methodological / inferential, not source-stated

No A&D entity is named as a Beagle target. The targeting profile is "software developers seeking Claude / Claude-Code tooling." Inferential A&D-adjacency:

1. **Developer toolchains in DIB enterprises increasingly use AI coding assistants.** A&D primes and Tier-1/2 suppliers operate dev environments with growing AI-tooling exposure. AI-brand-impersonation lures are a NEW initial-access vector that may scale across the industry as adoption broadens.
2. **DLL-sideloading via signed legitimate binary (G Data updater) is portable tradecraft.** The signed-binary-abuse pattern is not specific to Beagle; the same chain could be repurposed against other AI-brand impersonations (Copilot, ChatGPT, etc.) targeting any developer audience including DIB.
3. **Foothold-establishment backdoor on developer endpoints is a high-leverage starting point.** Developer endpoints typically have access to source repos, CI/CD credentials, cloud workloads, and signing keys — high-value pivot points if Beagle's operators chain follow-on capability onto established footholds.

Recommend `actor-profiler` flag the IOC set and tooling-overlap claim for cross-reference if (a) a second A/B-grade source confirms the PlugX-operator overlap, (b) APT41 dossier review surfaces matching infrastructure or DLL-sideloading patterns, or (c) any DIB-environment Beagle observation surfaces in first-party telemetry.
