# Morning Brief — 2026-07-28

**Arista shipped patches for the actively-exploited, CVSS 10.0 VeloCloud Orchestrator flaw (CVE-2026-16812) — the accelerated federal remediation deadline is 48 hours out (July 30), and the fix, a confirmed maximum-severity score, and 3 attacker hunt-IPs all landed overnight.** This is the one action-forcing item on an otherwise unchanged board.

**Why it matters:** VeloCloud Orchestrator is the SD-WAN control plane — a single unauthenticated command-injection compromise pushes configuration and routing changes fabric-wide, so for an A&D enterprise this is a network-fabric exposure, not a single-appliance risk. The exposure is now closable; the clock is short.

## 🚨 Active Threats

**Fastjson 1.x carries an actively-exploited, unpatched RCE (CVE-2026-16723) — flagged in this morning's 06:25 FLASH**
- What: SecurityWeek relays ThreatBook and Imperva telemetry of in-the-wild exploitation of [CVE-2026-16723](../vulnerabilities/CVE-2026-16723/profile.md) — a CVSS 9.0 unauthenticated, no-interaction RCE in the end-of-life Fastjson 1.x Java library (versions 1.2.68–1.2.83) via a crafted `@type` payload.
- Why it matters for A&D: Fastjson is a Log4j-class ubiquitous Java library; because 1.x is end-of-life there is **no patch**, so unpatched Java estates across the DIB are a durable initial-access surface. No A&D victim is named — targeting is broad commercial (US/Singapore/Canada).
- Action: inventory for Fastjson 1.2.68–1.2.83 and remediate the only way available — migrate to Fastjson 2.x (not affected) or enable SafeMode. Exploitation is live, so exposed instances remain **likely** targets.
- Source: [SecurityWeek](https://www.securityweek.com/unpatched-fastjson-vulnerability-exploited-in-attacks/) · Digraph: B2 (single-source veto — one retrievable relay carries all three originators; not CISA-KEV as of the 06:00 sweep). No actor named (Hard Rule 2).
- Continuity: already posted in flash-2026-07-28-0625 this morning — carried here as an action row for the record, not a re-lead.
