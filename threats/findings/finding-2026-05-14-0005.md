# CISA KEV adds CVE-2026-20182 Cisco Catalyst SD-WAN Controller auth bypass (CVSS 10.0) with 3-day federal deadline; Talos attributes active ITW exploitation to UAT-8616 cluster at high confidence

## Summary

CISA added CVE-2026-20182 to the Known Exploited Vulnerabilities Catalog on 2026-05-14 with a **3-day federal remediation deadline (dueDate 2026-05-17)** under Emergency Directive 26-03. The CVE is a **CVSS 10.0 maximum-severity unauthenticated pre-auth authentication bypass** in Cisco Catalyst SD-WAN Controller (vSmart) and Cisco Catalyst SD-WAN Manager (vManage). Cisco's affected-deployment list explicitly names **Cisco SD-WAN for Government (FedRAMP)** alongside On-Premises and Cloud tiers — placing this CVE in direct scope for DIB / CMMC / DFARS 252.204-7012-cleared environments.

Cisco Talos published a parallel research piece attributing the in-the-wild activity to a cluster they track as **UAT-8616 with "high confidence"** — characterized as "a highly sophisticated cyber threat actor" with prior exploitation of CVE-2026-20127 (a related authentication bypass) in the same product family since at least 2023. Talos notes UAT-8616's infrastructure overlaps with **Operational Relay Box (ORB) networks** that Talos monitors closely; this is a procedural observation, NOT a nation-state attribution claim, and Archimedes does not extrapolate per Hard Rule 2.

This is the **first CVSS 10.0 maximum-severity CVE** the Archimedes corpus has tracked. The 3-day federal deadline is the second-shortest KEV deadline tracked (Copy Fail's 14-day window from 2026-05-01 was the prior baseline). Cisco's framing of ITW exploitation is hedged at "limited," and Talos's UAT-8616 cluster designation is single-vendor at evaluation time (no Mandiant / MSTIC / CrowdStrike / Unit 42 parallel attribution in window) — single-source veto applies on the attribution layer with WEP ceiling at "likely."

## Technical detail

**CVE-2026-20182** is a pre-authentication authentication bypass in the vdaemon service on Cisco Catalyst SD-WAN Controller (vSmart) and Cisco Catalyst SD-WAN Manager (vManage). The flaw allows a remote unauthenticated attacker to send specially-crafted DTLS traffic to UDP port 12346 and "become an authenticated peer" — yielding the ability to manipulate network configuration via NETCONF without any valid credentials. The CVSS v3.1 score of 10.0 is maximum severity, consistent with the pre-auth network-attack-vector profile against a network-control plane component.

**Affected deployments** explicitly named by Cisco:
- On-Premises Cisco Catalyst SD-WAN
- Cisco SD-WAN Cloud-Pro
- Cisco SD-WAN Cloud (Cisco Managed)
- **Cisco SD-WAN for Government (FedRAMP)** — direct DIB / CMMC / DFARS 252.204-7012 scope

**Post-compromise pattern attributed to UAT-8616** (per Talos):
- Add SSH keys for persistent administrative access
- Modify NETCONF configurations to alter network behavior
- Escalate to root privileges on the SD-WAN controller appliance

**UAT-8616 track record per Talos:**
- Active since at least 2023 against the same product family
- Previously exploited CVE-2026-20127 (related authentication bypass)
- Same post-compromise pattern across both CVE exploitations (SSH keys + NETCONF + root)
- Infrastructure overlap with Operational Relay Box (ORB) networks Talos monitors closely

**Important scope note on Talos IOC clusters:** Talos's 10 cluster IOC sets in this publication are exploitation of the EARLIER, DISTINCT **CVE-2026-20133 / CVE-2026-20128 / CVE-2026-20122** trio (patched February 2026, with ZeroZenX Labs public PoC and "XenShell" JSP webshell released March 2026). These earlier exploitation clusters are **NOT UAT-8616-attributed** under Talos's framing. UAT-8616's specific CVE-2026-20182 in-the-wild activity has the behavioral post-compromise pattern (SSH keys + NETCONF + root) but no published infrastructure IOCs in this Talos piece beyond the behavior. The 10 cluster IOC sets remain useful enrichment for the parallel exploitation cohort of the same product family but should not be propagated as UAT-8616-attributed.

**Emergency Directive 26-03 framework context:** CISA's required action explicitly cross-references Emergency Directive 26-03 ("Mitigate Vulnerabilities in Cisco SD-WAN Systems") plus the Supplemental Direction ED 26-03 hunt and hardening guidance — signaling this KEV add operates within an established CISA-coordinated SD-WAN-vulnerability response framework, not as an isolated event.
