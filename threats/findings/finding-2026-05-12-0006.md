# CISA 2026-05-12 ICS Advisory Batch — Six Advisories, Three Vendors, 10+ CVEs Including ABB AC500 V3 CVSS 9.8 OOBW Headliner; No In-The-Wild Exploitation

## Summary

CISA published a six-advisory ICS batch on 2026-05-12 at 08:00 EDT
covering three vendors and four product families. The headliner is
**CVE-2025-15467** (ICSA-26-132-05): a **CVSS 9.8 Critical** out-of-
bounds write in the **ABB AC500 V3** PLC platform's cryptographic
message syntax parser (CMS / AEAD / AES-GCM ASN.1 IV parameter
handling), enabling crash / DoS / potentially RCE. The cluster also
covers an ABB AC500 V3 multi-CVE high-severity batch (forced browsing
/ certificate-key permission / null-pointer-deref), the ABB WebPro
SNMP Card PowerValue UPS-monitoring card, the ABB Automation Builder
Gateway, the Subnet Solutions PowerSYSTEM Center SCADA platform
(4-CVE cluster), and the Fuji Electric Tellus HMI / SCADA software.
CISA states no in-the-wild exploitation for any advisory; all six
have patches / firmware updates available at-disclosure. The
"publicly reported vulnerability" phrasing on CVE-2025-15467 is
CISA's standard language indicating prior third-party disclosure of
the underlying flaw, NOT an ITW claim (KEV catalog is the proper
authority and confirms no KEV entry for any of these CVEs). No A&D
prime is named in any advisory. The batch landed JUST AFTER the
07:30 EDT morning collection sweep boundary — surfaced by the 15:30
EDT pre-brief sweep's backstop-reach-to-morning-brief window.

### CVE-2025-15467 — ABB AC500 V3 Stack Buffer Overflow (HEADLINER)

- Product: ABB AC500 V3 PM5xxx 3.9.0, 3.9.0_HF1
- Class: Out-of-bounds write in cryptographic message syntax parser
  (CWE-787)
- Severity: Critical
- CVSS v3: 9.8
- Mechanism: When parsing CMS (Auth)EnvelopedData structures using
  AEAD ciphers such as AES-GCM, the IV (Initialization Vector)
  encoded in the ASN.1 parameter could be processed in a way that
  triggers a stack buffer overflow leading to crash, denial-of-
  service, or potentially remote code execution.
- ITW exploitation: not reported; the "publicly reported vulnerability"
  phrasing in the advisory indicates prior third-party disclosure of
  the underlying flaw, NOT active ITW exploitation. KEV catalog
  confirms no KEV entry.
- Critical Infrastructure Sectors: Chemical, Critical Manufacturing,
  Energy, Water and Wastewater
- Countries/Areas Deployed: Worldwide
- Why headliner: CVSS 9.8 + cryptographic-parser bug class
  (PoC-velocity-relevant) + "publicly reported" framing (third-party
  disclosure of underlying flaw exists somewhere) + ABB AC500 V3 is
  deployed in industrial automation including defense manufacturing
  facilities. This is the second consecutive CISA ICS advisory window
  in 2026 with a ruggedized-or-industrial-networking critical RCE
  landing — paired with the Siemens RUGGEDCOM ROX SSA-081142 +
