# Morning Brief — 2026-07-15

**SonicWall confirms active in-the-wild exploitation of a CVSS 10.0 unauthenticated flaw in its SMA1000 remote-access gateway — and has now shipped patches.** Fixed versions exist and a BOD 22-01 federal deadline applies to the KEV listing. Patch CVE-2026-15409 now.

**Why it matters:** SMA1000 is an internet-facing perimeter remote-access gateway common across DIB and Tier-1/2 supplier estates. An unauthenticated SSRF on the perimeter is a classic breach-entry primitive — and the fix window is now open, so unpatched exposure is a choice.

## 🔓 Vulnerabilities

**UPDATE: SonicWall PSIRT confirms SMA1000 zero-days are exploited — CVSS 10.0, patches now available**

- What: SonicWall's PSIRT confirmed active in-the-wild exploitation of **CVE-2026-15409** (unauthenticated server-side request forgery, Workplace interface, **CVSS 10.0 Critical**) and **CVE-2026-15410** (post-auth OS command injection, Management Console, CVSS 7.2), and released fixes — a second institutional attestation behind CISA's 2026-07-14 KEV listing.
- New since the 2026-07-14 afternoon brief: vendor confirmation of exploitation, CVSS scores, **fixed versions (platform-hotfix 12.4.3-03453 and 12.5.0-02835, and later)**, affected models (SMA1000 6210 / 7210 / 8200v), and four defender detection indicators. This resolves the prior "remediation target unspecified" caveat — the patch target is now identifiable.
- Confidence: active exploitation is **likely**, not raised to very likely. Two institutions attest it, but their evidence bases likely overlap — CISA's KEV determination for a vendor-disclosed zero-day would typically draw on SonicWall's own IR — and the PSIRT advisory reached us relay-only, not directly retrieved. The single-source veto caps confidence at likely. Neither source asserts an SSRF-to-RCE chain; do not assume the two CVEs chain.
- First-party (Hard Rule 8): `archimedes` + `defenseclaw_local` returned **0 IOC hits** (-48h, both indices reachable). SMA1000 perimeter-appliance logs are not forwarded to first-party telemetry, so this silence is non-probative — not reassurance.
- Detection (defender-side, from the PSIRT advisory): suspicious `/wsproxy` requests with unusual host parameters returning HTTP 101 (SSRF signal); login/logout API requests returning HTTP 200 in `extraweb_access.log`; hotfix rollbacks with path-traversal-style names in `ctrl-service.log`.
- No threat actor attributed (Hard Rule 2 — SonicWall names none). No atomic network IOCs published.
- Source: [BleepingComputer relaying SonicWall PSIRT](https://www.bleepingcomputer.com/news/security/sonicwall-warns-of-sma1000-flaws-exploited-in-zero-day-attacks-patch-now/) · CISA KEV v2026.07.14 · Digraph: A2 · WEP: likely · finding-2026-07-14-0007
