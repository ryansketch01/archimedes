# Microsoft warns of Windows IIS pre-auth RCE zero-day CVE-2026-30445; patch ships 2026-05 Patch Tuesday

## Summary

Microsoft MSRC issued a pre-release advisory 2026-05-05 01:00 EDT for CVE-2026-30445, a pre-authentication remote code execution vulnerability in the HTTP.sys driver underpinning Internet Information Services (IIS). Microsoft characterized exploitation as "limited, targeted in-the-wild" but named no actor and published no IOCs. CVSS 9.8 per MSRC. Affected products: Windows Server 2019, 2022, and 2025 with the IIS role installed and HTTP/2 enabled (the default). The patch ships 2026-05-13 in the regular May Patch Tuesday cadence. As an interim mitigation Microsoft recommends disabling HTTP/2 (`netsh http set HTTP2 enabled=false`) where the patch cannot deploy within seven days. CISA acknowledged the MSRC notice and flagged a pending KEV addition once exploitation criteria are formally validated. Single-source veto applies — corroboration test fails because CISA acknowledgment is a process notice, not independent telemetry — WEP capped at "likely."

## Technical detail

- **CVE:** CVE-2026-30445
- **Vendor / product:** Microsoft Windows Server — Internet Information Services (IIS) HTTP.sys driver
- **Class:** Pre-authentication remote code execution via crafted HTTP/2 request
- **CVSS (MSRC pre-release):** 9.8 (Critical)
- **Affected products:** Windows Server 2019, 2022, 2025 with IIS role installed and HTTP/2 enabled (default)
- **Patch status:** **No patch available at finding creation.** Ships in 2026-05 Patch Tuesday on 2026-05-13.
- **Exploitation status (MSRC):** "Limited, targeted in-the-wild exploitation observed"
- **Mitigation:** Disable HTTP/2 via `netsh http set HTTP2 enabled=false` for systems unable to deploy the patch within seven days. Trade-off: may degrade some modern client interactions; does not break protocol compatibility.
- **Historical context:** HTTP.sys has prior memory-corruption history (MS15-034 / CVE-2015-1635, CVE-2021-31166). Driver runs in kernel space — RCE is privileged.
- **Attribution:** None. Microsoft did not name an actor. Per Hard Rule 2, Archimedes does not originate.
