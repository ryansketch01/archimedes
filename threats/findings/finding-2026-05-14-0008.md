# OpenAI confirms TanStack supply-chain breach — 2 employee devices, multi-platform code-signing-cert rotation, no customer data exposure per internal investigation

## Summary

OpenAI publicly confirmed on 2026-05-14T15:07 EDT (via BleepingComputer's Lawrence Abrams) that **two employee devices were compromised** during the Mini Shai-Hulud / TanStack supply-chain campaign — the TeamPCP-attributed npm + PyPI worm tracked in the Archimedes vulnerability index as **VT-006 (CVE-2026-45321, CVSS 9.6)**. This is the **first named-enterprise-victim confirmation** in the Archimedes corpus on the Mini Shai-Hulud campaign, downstream of finding-2026-05-12-FLASH-0001 (Wiz + Snyk + StepSecurity originating).

OpenAI's bounded-scope framing: 2 employee devices compromised, "limited subset of internal source code repositories" accessed, limited credentials stolen, **no customer data exposure**, **no production-system compromise**, **no intellectual property exposure**, **no deployed software compromise**. OpenAI is **rotating code-signing certificates for macOS, Windows, iOS, and Android** despite no detected abuse — a precautionary response consistent with the worm's documented credential-exfil scope (GitHub tokens, npm tokens, AWS credentials, SSH keys). **macOS users must update OpenAI desktop applications before 2026-06-12** or older-cert-signed apps may fail to launch. Windows and iOS users unaffected by the app-relaunch caveat.

The multi-platform cert rotation event is significant — it suggests OpenAI is treating the credential-exfil scope as broader than the surface "2 devices" implies (precautionary rotation across all platforms suggests cert keys may have been present on the compromised devices). Microsoft Threat Intelligence is referenced for "related Linux-malware variants" of the campaign; Socket + Aikido are tracking compromised packages. **No A&D-prime direct exposure in this surface**, but the OpenAI cert-rotation pattern is the operational template for what an A&D-prime victim disclosure would look like if @squawk dependencies reach Tier-1 A&D SDLCs (Boeing / Airbus / Honeywell Aerospace / Safran).
