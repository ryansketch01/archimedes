# NVIDIA TensorRT-LLM dual deserialization criticals — CVE-2025-33255 (MPI server) + CVE-2026-24142 (unsafe serialized handle) — NIST 9.8 / NVIDIA-CNA 6.3 disagreement on the second

## Summary

NVIDIA PSIRT advisory a_id=5805 (published 2026-05-20) and NIST NVD
jointly disclosed two critical deserialization vulnerabilities in
NVIDIA TensorRT-LLM versions <1.2. Both are CWE-502. CVE-2025-33255
is an MPI server unsafe-deserialization issue (NIST CVSS 9.8 network
unauth); CVE-2026-24142 is an unsafe-serialized-handle issue with a
3.5-point CVSS disagreement between NIST (9.8 network unauth, full
CIA) and NVIDIA-CNA (6.3 MEDIUM, local-privileged, low-CIA via
scope-change). Both patched in TensorRT-LLM 1.2 at disclosure. No
active exploitation attested by any source. No actor named. The
disagreement reflects fundamentally different attack-surface
assumptions worth analyst attention.

## Technical detail

- NVIDIA-CNA score: not separately published in NVD record snapshot
- CWE-502 Deserialization of Untrusted Data
- Component: MPI server (TRT-LLM internal distributed-inference layer)
- Impact per NVD record: code execution, DoS, data tampering,
  information disclosure
- Affected: NVIDIA TensorRT-LLM all platforms, versions <1.2
- Fixed in: TensorRT-LLM 1.2
- Active exploitation: none referenced
- Note: CVE prefix is 2025 (NVIDIA CVE pre-assignment practice;
  bound to same NVIDIA PSIRT advisory and same fixed version as
  CVE-2026-24142)

### CVE-2026-24142 — TRT-LLM unsafe serialized handle

- CVSS v3.1 (NIST): **9.8 CRITICAL** — AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H
- CVSS v3.1 (NVIDIA-CNA): **6.3 MEDIUM** — AV:L/AC:L/PR:L/UI:N/S:C/C:L/I:L/A:L
- CVSS disagreement spread: 3.5 points
- CWE-502 Deserialization of Untrusted Data
- Component: TRT-LLM serialization (unsafe serialized handle)
- Impact: code execution, data tampering, information disclosure
- Affected: NVIDIA TensorRT-LLM all platforms, versions <1.2
- Fixed in: TensorRT-LLM 1.2
- Active exploitation: none referenced

### CVSS disagreement — what it means operationally

| Vector dimension | NIST | NVIDIA-CNA |
|---|---|---|
| Attack vector | Network | Local |
| Privileges required | None | Low |
| Scope | Unchanged | Changed |
| C/I/A impact | High/High/High | Low/Low/Low |

NIST's scoring implies the bug is reachable over the network without
authentication and produces full CIA-triad compromise. NVIDIA-CNA's
scoring implies the attacker needs local + low-privilege access
(e.g., a multi-tenant GPU server scenario), capped at low-impact
data tampering across a scope-change boundary.

Per INTEL-GRADING vendor-primary precedence, NVIDIA PSIRT's score
takes precedence when assessing first-party A&D-prime deployment
exposure (typical TRT-LLM deployments are container-isolated GPU
inference endpoints, often inside private VPCs — closer to the
"local + privileged" attack-surface model than "network unauth").
However, public-facing inference endpoints or shared GPU multi-
tenant scenarios extend the attack surface materially closer to
the NIST scoring ceiling.

## A&D-prime relevance — STRUCTURAL-INDIRECT

NVIDIA TensorRT-LLM is the LLM inference optimization library
widely used in enterprise AI inference deployments. A&D-prime
exposure depends on internal LLM R&D platform deployment posture
(private-VPC container-isolated → NVIDIA-CNA scoring model;
customer-facing or multi-tenant → NIST scoring model; sovereign /
classified deployments → NVIDIA-CNA scoring model with additional
segmentation).

No A&D-prime is named as a customer at the disclosure layer. No
customer-impact statements are anticipated near-term (NVIDIA PSIRT
publishes against the product, not against specific customer
deployments). Per Hard Rule 2, Archimedes does not extrapolate to
specific A&D-prime exposure beyond what sources state.
