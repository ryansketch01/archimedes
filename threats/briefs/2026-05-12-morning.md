# Morning Brief — 2026-05-12

**[A TeamPCP-attributed npm and PyPI worm — "Mini Shai-Hulud" — compromised 169–172 packages overnight including 19 @squawk aviation-developer packages, and per Wiz and Snyk is the first publicly documented validly-attested supply-chain worm within the Shai-Hulud family lineage.](https://thehackernews.com/2026/05/teampcp-mini-shai-hulud-worm-npm-pypi-attested.html)** Maintainer-side reversion ran same day; the worm's OIDC-token-hijack mechanism produces malicious packages carrying valid SLSA provenance, breaking the attestation trust posture npm has been building toward.

**Why it matters:** A&D primes and DIB suppliers running CI/CD pipelines that pull from npm or PyPI now have a documented case of validly-attested malicious packages; an SBOM-and-attestation policy alone no longer floors out the supply-chain attack class. The @squawk aviation-developer ecosystem hit appears incidental via worm maintainer-enumeration, not strategic A&D targeting, but the dependency-graph reach into A&D-prime SDLCs is the operative inventory question for today.

**[Siemens May 2026 Patch Tuesday discloses five CVEs across ROS#, RUGGEDCOM ROX, and SIMATIC; CVE-2026-41551 (SSA-357982) in the ROS# .NET library is UNAUTHENTICATED CVSS 9.1 v3.1 / 9.3 v4.0 path traversal with arbitrary file read AND write.](https://cert-portal.siemens.com/productcert/html/ssa-357982.html)** ROS# is Siemens' .NET interop layer for the Robot Operating System — robotics middleware deployed in aerospace and defense R&D contexts (military UGV / UAV ground control, collaborative manufacturing robotics, simulation tooling).
