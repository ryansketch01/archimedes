## 🚨 Active Threats

**UPDATE: GitHub confirms poisoned Nx Console extension caused 3,800-repo internal breach**
- What: GitHub's statement, relayed independently by The Hacker News and BleepingComputer, attributes the May 20 internal-repo breach to a compromised employee device running a poisoned `nrwl.angular-console` VS Code extension. The Hacker News, sourcing the Nx Team, specifies an 18-minute publish-and-withdraw window (2026-05-18 12:30–12:48 UTC) and names OpenAI, Mistral AI, and Grafana Labs as secondary victims in the same TanStack supply-chain chain.
- Why it matters for A&D: Every Tier-1 SDLC running VS Code Marketplace plugins is structurally inside the blast radius. Inventory developer-workstation extensions and pin to known-good versions today.
- Source: [The Hacker News](https://thehackernews.com/2026/05/github-internal-repositories-breached.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/github-links-repo-breach-to-tanstack-npm-supply-chain-attack/) · Digraph: A2 · WEP: very likely (procedural) / likely (TeamPCP attribution)
- Related: [Actor #001 TeamPCP](../threat-actors/TeamPCP/) · VT-006 / CVE-2026-45321 · finding-2026-05-21-0002
- Hard Rule 2: **TeamPCP attribution is restated per Wiz + StepSecurity per prior reporting (Snyk relays StepSecurity, not independent). Archimedes does NOT originate.** GitHub names no actor.
- 🔗 **Update on:** [2026-05-20 FLASH](2026-05-20-flash-teampcp-github-internal-repos.md) — vendor framing moves from "directionally consistent" to direct causal statement on the extension vector.

**UPDATE: Defender zero-day pair gains codenames — CVE-2026-41091 (UnDefend, LPE, 7.8) + CVE-2026-45498 (RedSun, DoS, 4.0)**
