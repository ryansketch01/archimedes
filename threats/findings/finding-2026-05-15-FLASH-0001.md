# Microsoft Exchange Server on-Prem Zero-Day CVE-2026-42897 — Active Exploitation per MSRC, No General-Availability Patch (ESU-Only Path)

## Summary

Microsoft Security Response Center disclosed CVE-2026-42897 on 2026-05-15, a cross-site scripting (XSS) vulnerability in on-premises Microsoft Exchange Server tagged "Exploitation Detected" per Microsoft's exploitation-status taxonomy. The flaw allows an unauthenticated network attacker to execute arbitrary JavaScript in a victim's browser context via a crafted email; exploitation triggers when the victim opens the message in Outlook Web Access (OWA) under specific interaction conditions. NVD published the CVE record on 2026-05-14 with CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:N (8.1 HIGH), CWE-79.

Affected products are on-prem only: Exchange Server 2016, Exchange Server 2019, and Exchange Server Subscription Edition (SE), all update levels. Exchange Online is not affected. No general-availability patch is currently published — Microsoft is shipping binary patches via the Extended Security Updates (ESU) program only (SE RTM, 2016 CU23, 2019 CU14/CU15). For non-ESU customers, the mitigation path is the Exchange Emergency Mitigation Service (EEMS), which automatically applies a URL-rewrite rule, plus the Exchange on-premises Mitigation Tool (EOMT) script for air-gapped environments.
