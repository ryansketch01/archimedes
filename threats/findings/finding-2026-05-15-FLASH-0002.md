## Summary

SecurityWeek (Ionut Arghire byline, 2026-05-15 05:47 EDT) reports that TeamPCP — tracked actor #001 (HIGH), corpus-attributed operator of the Mini Shai-Hulud npm + PyPI worm (VT-006 / CVE-2026-45321) per Wiz + Snyk + StepSecurity 2026-05-12 — released the Shai-Hulud worm's source code via GitHub repositories under multiple user accounts. ## TTP-change analysis (Trigger 4)

Per VT-006 corpus state + the 2026-05-12 FLASH brief (`flash-2026-05-12-0600`), TeamPCP's prior operational pattern was **private operator-controlled deployment** of the Mini Shai-Hulud worm against npm + PyPI maintainer accounts via SLSA-attestation-breaking OIDC token hijack.

The new behavior — open-source release of the worm's source code on GitHub PLUS a BreachForums-fronted cybercriminal-bounty model — is a meaningful TTP departure across three dimensions:

1. **Distribution model:** Private operator-controlled deployment → commodity-style open-source release. Shifts TeamPCP from single-operator to campaign-host role.

2. **Force multiplication:** Bounty mechanism explicitly solicits third-party deployment with proof-of-intrusion economics. Future Shai-Hulud-derivative intrusions may not be TeamPCP itself but cybercriminals motivated by the BreachForums challenge.

3. **Attribution complexity:** Future Shai-Hulud-derivative intrusions become attribution-ambiguous between TeamPCP and the broader BreachForums cybercriminal pool. The 2026-05-12 VT-006 attribution chain (Wiz / Snyk / StepSecurity → TeamPCP) does NOT automatically extend to derivative campaigns. Analyst SAT-ACH should consider this attribution-ambiguity in any forward-look call on Shai-Hulud-derivative intrusions over the next 30 days.

This pivot is also coherent with the 2026-05-14 22:00 EDT FLASH on TeamPCP's Mistral AI 450 repos sale (`raw-2026-05-14-flash-2200-001`) — TeamPCP is broadly shifting toward monetization / commoditization of stolen or developed cybercriminal capability across multiple distribution channels.
