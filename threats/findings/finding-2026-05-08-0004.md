# ClaudeBleed — LayerX discloses trust-boundary flaw in Claude Chrome extension allowing AI-agent takeover; Anthropic partial patch incomplete per researcher

## Summary

LayerX disclosed via SecurityWeek a vulnerability dubbed "ClaudeBleed"
in Anthropic's Claude Chrome extension. The flaw is a trust-boundary
violation: the extension trusts the origin (claude.ai) of the
execution context but does not verify the execution context, allowing
a hostile co-resident Chrome extension to inject content scripts into
the Main world running on claude.ai, inject prompts into the Claude AI
agent, forge user-approval confirmations via DOM manipulation, and
exfiltrate from connected Gmail / GitHub / Google Drive sessions or
take destructive actions on the victim's behalf. Anthropic has issued
a partial patch; LayerX states the fix is incomplete because attackers
can switch the Claude extension into 'privileged' mode without user
notification. No CVE assigned, no CVSS published, no active exploitation
reported. Single-source effective (LayerX research relayed by
SecurityWeek). AI-tradecraft-watch theme continuation from 2026-05-07
afternoon brief.

## Technical detail

The Claude Chrome extension reportedly trusts the origin (claude.ai)
of the page on which it executes but does not verify the execution
context (i.e., does not check whether the script invoking it runs in
the legitimate extension context vs an injected content script
running in the Main world from a separate, hostile extension).

Per the LayerX-relayed research, a hostile extension can:

1. Inject content scripts into the Main world on the claude.ai page
2. Inject prompts into the Claude AI agent via the same surface
3. Forge user-approval confirmation messages via DOM manipulation
   (repeatedly sending DOM events that the legitimate extension
   interprets as user clicks)
4. Bypass the user-notification flow entirely

Capabilities exposed via takeover: data exfiltration from
authenticated Gmail / GitHub / Google Drive sessions, sending email
on the victim's behalf, deletion of user data, unauthorized document
sharing.

Anthropic's patch reportedly added internal security checks for
'standard' mode extensions. LayerX's published bypass: a hostile
extension can switch the Claude extension into 'privileged' mode
without user notification, evading the check.

No CVE assigned; no CVSS published.
