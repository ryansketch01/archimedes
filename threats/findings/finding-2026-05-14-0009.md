# node-ipc npm package — 3 malicious versions published by no-history "atiertant" account; ~90 credential categories exfil via dual-channel HTTPS-POST + DNS-TXT to sh.azurestaticprovider[.]net; unattributed

## Summary

Socket and StepSecurity have identified three malicious versions of the **node-ipc** npm package — versions **9.1.6, 9.2.3, and 12.0.1** — published by an account named **"atiertant"** with no prior publish history. The Hacker News relayed the disclosure on 2026-05-14T13:22 EDT. The last legitimate node-ipc publish was August 2024; node-ipc is a popular Node.js inter-process-communication library with deep dependency-graph reach into developer tooling.

The malicious versions exfiltrate **approximately 90 categories of developer credentials and cloud secrets** to attacker C2 at **sh.azurestaticprovider[.]net** via a **dual-channel exfil pattern: HTTPS-POST + DNS-TXT-record-encoding**. The malware uses **dual-DNS-resolver fallback (1.1.1.1 primary + 8.8.8.8 fallback)** to bypass environments that block one resolver. Persistence is via package-installation-time activation; activates on `npm install` of any affected version.

**Attribution is explicitly unstated.** Socket and StepSecurity do NOT claim Shai-Hulud / Mini Shai-Hulud / TeamPCP lineage at this disclosure surface, despite operational-pattern adjacency (developer-credential targeting via npm). The Hacker News framing notes "no specific threat actor family identified." Archimedes preserves the unattributed status verbatim per Hard Rule 2. **Compromise vector is undetermined** — credential-takeover of existing maintainer account, unauthorized maintainer addition via `npm owner add`, or sock-puppet account with malicious publish-permission — distinguishing requires npm-registry audit-log access neither vendor has published.

This is **operationally adjacent to but DISTINCT from Mini Shai-Hulud (VT-006)** — same developer-credential targeting class via npm, but no self-propagating worm logic, no SLSA-attestation breaking, no PyPI co-distribution. Grader treats as separate "npm supply-chain credential-theft cluster" (parallel to but not the same as VT-006).
